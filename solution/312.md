## 1. Problem

312. Burst Balloons
    
## 2. Summary

Mental Template:
- Interval DP
- “Last balloon to burst” trick

State:
dp[l][r] = max coins from bursting balloons inside (l, r)
(open interval)

Padding:
nums = [1] + nums + [1]

Transition:
for k in (l, r):
    dp[l][r] =
        max(
            dp[l][k]
          + dp[k][r]
          + nums[l] * nums[k] * nums[r]
        )

Meaning:
- Assume k is the LAST balloon burst in interval
- Left/right intervals already solved independently

Order:
- interval length from small -> large

Answer:
dp[0][n-1]

## 3. Key Points

### Problem Core & Goal

* **Objective:** Find the maximum coins obtainable by bursting all balloons.
* **Score Formula:** Bursting balloon $i$ yields $\text{nums}[i-1] \times \text{nums}[i] \times \text{nums}[i+1]$ coins.
* **Boundary Condition:** Balloons outside the array bounds are treated as virtual balloons with a value of `1`.
* **The Core Difficulty:** Dynamic dependencies. Bursting a balloon changes the adjacency of its remaining neighbors, making a straightforward greedy approach impossible.

---

### Algorithmic Thinking (Interval DP)

* **Reverse Thinking:** Instead of deciding which balloon to burst *first*, determine which balloon $k$ is the **last** to burst in a given range.
* **Static Boundaries:** If balloon $k$ is the last to burst in the open interval $(i, j)$, then all balloons between $i$ and $k$, and between $k$ and $j$, have already been burst. Thus, the remaining neighbors of $k$ are guaranteed to be the fixed boundaries $i$ and $j$.
* **Core Nature:** It is a **structured, cached brute-force search** ($O(n^3)$). It enumerates all possibilities but uses a DP table as a cache to completely eliminate redundant calculations.

---

### The 3-Tree Loop Architecture

* **Outer Loop (Window Size):** Iterates through all possible interval lengths from smallest (`2`) to largest (`n-1`). This guarantees smaller sub-intervals are solved and cached before larger ones are calculated.
* **Middle Loop (Window Sliding):** Shifts the window from left to right, defining the exact left boundary $i$ and right boundary $j$ for the current length.
* **Inner Loop (Decision Enumeration):** Tests every balloon $k$ between $i$ and $j$ as the "last-burst" candidate, selecting the one that maximizes total coins.

---

### State Transition Equation

$$dp[i][j] = \max_{i < k < j} \Big( dp[i][k] + dp[k][j] + \text{arr}[i] \times \text{arr}[k] \times \text{arr}[j] \Big)$$

* **`dp[i][k]`**: Maximum coins from bursting the left sub-interval.
* **`dp[k][j]`**: Maximum coins from bursting the right sub-interval.
* **`arr[i] * arr[k] * arr[j]`**: Coins obtained from bursting the final壓轴 balloon $k$ against the fixed boundaries $i$ and $j$.


## 4. Code Implementation:


```
class Solution:
    def maxCoins(self, nums: list[int]) -> int:
        arr = [1] + nums + [1]
        n = len(arr)
        dp = [[0] * n for _ in range(n)]
        
        for length in range(2, n):
            for i in range(0, n - length):
                j = i + length
                for k in range(i + 1, j):
                    total = dp[i][k] + dp[k][j] + arr[i] * arr[k] * arr[j]
                    if total > dp[i][j]:
                        dp[i][j] = total
                        
        return dp[0][n - 1]   

```
