## 1. Problem

133. Clone Graph
    
## 2. Summary

1. Maintain mapping: old node -> new node (store in dictionary).

2. If a neighbor has not been cloned:
   - Clone it
   - Update the dictionary
   - Add it to the queue for traversal
   - Nodes already in the dictionary should not be traversed again

3. If the neighbor exists in the dictionary:
   - Append the corresponding cloned neighbor to the cloned node's neighbors list



* Use `map` to store old node → new node, prevents duplicates and handles cycles.
* BFS/DFS to traverse all nodes.
* Clone neighbors by `map[cur].neighbors.append(map[nei])`.
* Return cloned start node: `map[node]`.


## 3. Key Points

* `node_map` = old node → new node, prevents duplicates & handles cycles
* BFS queue ensures all nodes are visited
* Append neighbors via `node_map[cur].neighbors.append(node_map[nei])` → builds new graph structure

## 4. Code Implementation:


```
   class Solution:
    def cloneGraph(self, node: Optional['Node']) -> Optional['Node']:
        if not node:
            return None
        ndict = {}
        ndict[node] = Node(node.val)
        q = deque()
        q.append(node)

        while q:
            cur = q.popleft()
            for nei in cur.neighbors:
                if nei not in ndict:
                    ndict[nei] = Node(nei.val)
                    q.append(nei)
                ndict[cur].neighbors.append(ndict[nei])
        return ndict[node]
        


```
