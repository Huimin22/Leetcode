## 1. Problem

513. Find Bottom Left Tree Value
    
## 2. Summary

BFS

`leftmost = q[0].val` — update it at the start of each level; the last update is the answer.

## 3. Key Points

* BFS level-order.
* Each level: `leftmost = q[0].val`.
* Enqueue children left → right.
* Last `leftmost` after BFS is answer.

## 4. Code Implementation:

```
class Solution:
    def findBottomLeftValue(self, root: Optional[TreeNode]) -> int:
        q = deque([root])
        while q:
            size = len(q)
            leftmost = q[0].val  
            for _ in range(size):
                cur_n = q.popleft()
                if cur_n.left:
                    q.append(cur_n.left)
                if cur_n.right:
                    q.append(cur_n.right)
        return leftmost   
```

## 5. Complexity Analysis
    Time：O(n)
        
    Space: O(1)
