## 1. Problem

78. Subsets
    
## 2. Summary

```python
res = []
def dfs(start, path):
    res.append(path[:])
    for i in range(start, len(nums)):
        path.append(nums[i])
        dfs(i+1, path)
        path.pop()
dfs(0, [])
return res
```

* **path** = current subset
* **dfs(i+1, path)** = move to next element
* **res.append(path[:])** = record every subset


## 3. Key Points


* Use **DFS / backtracking**.
* **Path** stores current subset.
* **Append path[:]** to result at each node.
* Loop `for i in range(start, len(nums))`.
* **dfs(i+1, path)** to move forward.
* **path.pop()** to backtrack.
* Start with `dfs(0, [])`.


## 4. Code Implementation:


```
class Solution:
    def subsets(self, nums: List[int]) -> List[List[int]]:
        res = []

        def dfs(start, path):
            res.append(path[:])
            for i in range(start, len(nums)):
                path.append(nums[i])
                dfs(i+1, path)
                path.pop()
        
        dfs(0, [])
        return res   
```
