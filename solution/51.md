## 1. Problem

51. N-Queens
    
## 2. Summary

```python
class Solution:
    def solveNQueens(self, n: int) -> list[list[str]]:
        res = []
        cols, diag1, diag2 = set(), set(), set()

        def dfs(row, path):
            if row == n:
                res.append(path[:])
                return
            for col in range(n):
                if col in cols or (row - col) in diag1 or (row + col) in diag2:
                    continue
                cols.add(col)
                diag1.add(row - col)
                diag2.add(row + col)
                row_str = "."*col + "Q" + "."*(n - col - 1)
                path.append(row_str)

                dfs(row + 1, path)

                path.pop()
                cols.remove(col)
                diag1.remove(row - col)
                diag2.remove(row + col)

        dfs(0, [])
        return res
```

**Quick Notes for Memory:**

* DFS row by row.
* Each layer = a row. Choices = available columns.
* Conflict check: `col`, `row-col` (left diag), `row+col` (right diag).
* Append row string to path.
* Backtrack after DFS.
* Terminate at `row == n` → add path to results.


## 3. Key Points

* DFS row by row, each row place one queen.
* Choices per row = columns 0..n-1.
* Conflict check:

  * Column occupied → `col in cols`
  * Left diagonal → `row - col in diag1`
  * Right diagonal → `row + col in diag2`
* Place queen → mark `cols`, `diag1`, `diag2` → append row string to path.
* Recurse next row.
* Backtrack → unmark sets, pop path.
* Terminate at `row == n` → valid solution → save path.
