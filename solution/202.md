## 4. Code Implementation:


```
class Solution:
    def isHappy(self, n: int) -> bool:
        def digit_square_sum(n):
            total = 0
            while n:
                n, digit = divmod(n, 10)
                total += digit**2
            return total

        seen = set()
        while n != 1 and n not in seen:
            seen.add(n)
            n = digit_square_sum(n)
        return n == 1   
```
