## 1. Problem

202. Happy Number
    
## 2. Summary

Here’s a **concise mental template** for **Happy Number (LC 202)** you can copy-paste:

```python
def isHappy(n):
    def digit_square_sum(x):
        total = 0
        while x:
            x, d = divmod(x, 10)
            total += d**2
        return total

    seen = set()
    while n != 1 and n not in seen:
        seen.add(n)
        n = digit_square_sum(n)
    return n == 1
```

## 3. Key Points

* Replace number with sum of squares of digits
* Track seen numbers to detect cycles
* Return True if reaches 1, else False

**Optional optimization:** use **fast/slow pointers** to detect cycles in O(1) space.

## 4. Code Implementation:


```
class Solution:
    def isHappy(self, n: int) -> bool:
        def digit_square_sum(n):
            total = 0
            while n:
                n, digit = divmod(n, 10)
                total += digit**2
            return total

        seen = set()
        while n != 1 and n not in seen:
            seen.add(n)
            n = digit_square_sum(n)
        return n == 1   
```

## 5. Complexity Analysis
    Time：O(n)
        
    Space: O(1)
