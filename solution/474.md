## 1. Problem

474. Ones and Zeroes
  
## 2. Summary

for s in strs: try different dp[i][j] and update dp[i][j]

```python
def findMaxForm(strs, m, n):
    dp = [[0]*(n+1) for _ in range(m+1)]
    
    for s in strs:
        zeros = s.count('0')
        ones = s.count('1')
        for i in range(m, zeros-1, -1):
            for j in range(n, ones-1, -1):
                dp[i][j] = max(dp[i][j], 1 + dp[i-zeros][j-ones])
    
    return dp[m][n]
```

## 3. Key Points

* 2D DP: `dp[zeros][ones]`
* Count zeros & ones per string
* Iterate **backwards** to avoid reuse
* Max of include / exclude
* Return `dp[m][n]`

## 4. Code Implementation:

```
class Solution:
    def findMaxForm(self, strs: List[str], m: int, n: int) -> int:
        dp = [[0]*(n+1) for _ in range(m+1)]
        for s in strs:
            zeros = s.count('0')
            ones = s.count('1')
            for i in range(m, zeros-1, -1):
                for j in range(n, ones-1, -1):
                    dp[i][j] = max(dp[i][j], dp[i-zeros][j-ones]+1)
        return dp[m][n]   

```
