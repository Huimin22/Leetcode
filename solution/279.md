## 1. Problem

279. Perfect Squares
     
## 2. Summary

dp[i] = min number of perfect squares that sum to i
dp[0] = 0

for i in 1..n:
dp[i] = +inf
for j in 1..floor(sqrt(i)):
square = j*j
dp[i] = min(dp[i], dp[i - square] + 1)

## 3. Key Points

key idea: last move choose a square number
transition: i = (i - square) + square

## 4. Code Implementation:


```
class Solution:
    def numSquares(self, n: int) -> int:
        dp = [float('inf')] * (n + 1)
        dp[0] = 0

        for i in range(1, n + 1):  # target
            for j in range(1, int(i ** 0.5) + 1):  # possible square roots
                square = j * j
                dp[i] = min(dp[i], dp[i - square] + 1)

        return dp[n]   
```

## 5. Complexity Analysis
    Time：O(n)
        
    Space: O(1)
