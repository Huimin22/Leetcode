## 1. Problem

237. Delete Node in a Linked List
    
## 2. Summary

Here’s your explanation in **Markdown format**:

```markdown
- The node with value `5` is merged with the next node `1`.
- The original node keeps its **address**, but its **value becomes 1**.
- Its `next` pointer now points to the node after `1` (`9` in this case).
```

## 3. Key Points




## 4. Code Implementation:

```
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None

class Solution:
    def deleteNode(self, node):
        """
        :type node: ListNode
        :rtype: void Do not return anything, modify node in-place instead.
        """
        node.val = node.next.val
        node.next = node.next.next

```


## 5. Complexity Analysis
    Time：O(n)
        
    Space: O(1)
