## 1. Problem

26. Remove Duplicates from Sorted Array
    
## 2. Summary

Use two pointers:

fast scans the array.
slow points to the next position for a unique number.
If nums[fast] is different from nums[slow - 1], copy it to nums[slow].
Return slow as the number of unique elements.

## 3. Key Points

Sorted array → duplicates are next to each other.
fast → find new elements.
slow → place new elements.
slow represents the next position to write.
slow - 1 → the last unique element.
return slow → number of unique elements.
Pattern: Fast finds, Slow writes.

## 4. Code Implementation:


```
/**
 * @param {number[]} nums
 * @return {number}
 */
var removeDuplicates = function(nums) {
    let slow = 1;
    for (let fast = 1;fast<nums.length;fast++) {
        if (nums[slow-1] != nums[fast]) {
            nums[slow] = nums[fast];
            slow ++;

        }

    }
    return slow;
};   


```

## 5. Complexity Analysis
    Time：O(n)
        
    Space: O(1)
