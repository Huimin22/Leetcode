## 3. Key Points


## 1️⃣ Path Shapes

There are two possible path shapes in this problem:

1. **Straight path** (a line extending up from a node)

   * This path can continue to the parent
   * Example: `15 → 20 → parent of 20`
   * **Return value** is the sum of this path
2. **Peak path** (both left and right + current node)

   * This path **cannot continue to the parent**, otherwise nodes would be reused
   * Example: `15 → 20 ← 7`
   * This forms a complete local maximum path
   * **Cannot be returned to parent**, only recorded in the global max

---

## 2️⃣ Return Value vs Global Maximum

| Concept      | Purpose              | Left/Right | Add Node | Can be used by parent? |
| ------------ | -------------------- | ---------- | -------- | ---------------------- |
| Return value | Extend upward        | Only one   | Current  | ✔                      |
| Global max   | Record complete path | Both       | Current  | ✖ (update only)        |

* **Return value selects one side only**: keeps path valid for parent extension
* **Global max updates peak**: records complete peak path, ensures local maximums are captured

💡 **Formula:**

```text
Path to parent = node.val + max(left, right)
Local peak path = node.val + left + right
```

---

## 3️⃣ Why it works

* Every node updates the **global maximum** → all possible paths are considered
* Return value to parent is “extendable contribution” → recursion remains valid
* Final `self.max_sum` holds **maximum path sum in the tree**, whether it passes through root or not

> In other words:
> **Return value is only part of the recursion, not the answer**
> **Answer is recorded in global variable**, covering all peak paths

---

## 4️⃣ Analogy

Imagine climbing a mountain:

* You can walk up a trail (return value)
* But the peak may have a complete mountain with high left and right sides; you take a photo at the peak (global max)
* Parent node can only continue along one trail, cannot carry the whole peak
* The largest photo among all peaks is the final answer
