## 1. Problem

285 Inorder Successor in BST
    
## 2. Summary

**BST Inorder Successor – Core Idea**

* Inorder traversal of a BST is sorted
* Successor = smallest node greater than p

---

### Case 1: p has right subtree

* Successor is in right subtree
* Go right once, then keep going left
* Result = leftmost node in right subtree

---

### Case 2: p has no right subtree

* Successor is in ancestors
* Start from root and search:

Rules:

* If p < cur → cur is a candidate, move left
* If p ≥ cur → move right
* Last recorded candidate is the successor



**Key**

* BST property → decide direction
* always try to find smallest > p

**Iterative**

```
res = None
cur = root
while cur:
    if p.val < cur.val:
        res = cur
        cur = cur.left
    else:
        cur = cur.right
return res
```

## 3. Key Points

* inorder = sorted → successor = next larger
* right subtree exists → right once + leftmost
* no right → search from root
* p.val < cur.val → update res, go left
* else → go right
* result = smallest node > p
* O(h), no extra space
