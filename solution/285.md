## 2. Summary

**LC 285 Inorder Successor in BST — Mental Template**

* inorder = sorted
* successor = next larger than p

**Case 1: p.right exists**

* go right once
* then go left all the way
* return that node

**Case 2: no right**

* start from root
* if p.val < cur.val → record cur, go left
* else → go right
* last recorded = answer

**Key**

* BST property → decide direction
* always try to find smallest > p

**Iterative**

```
res = None
cur = root
while cur:
    if p.val < cur.val:
        res = cur
        cur = cur.left
    else:
        cur = cur.right
return res
```

## 3. Key Points

* inorder = sorted → successor = next larger
* right subtree exists → right once + leftmost
* no right → search from root
* p.val < cur.val → update res, go left
* else → go right
* result = smallest node > p
* O(h), no extra space
