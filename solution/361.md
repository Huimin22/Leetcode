## 1. Problem

361. Bomb Enemy
     
Given a 2D grid, each cell is either a wall 'W', an enemy 'E' or empty '0' (the number zero), return the maximum enemies you can kill using one bomb.
The bomb kills all the enemies in the same row and column from the planted point until it hits the wall since the wall is too strong to be destroyed.
Note that you can only put the bomb at an empty cell.

Example:

For the given grid

0 E 0 0

E 0 W E

0 E 0 0

return 3. (Placing a bomb at (1,1) kills 3 enemies)


## 2. Summary

Scan row by row and column by column.
Use row_hits (int) for current row segment enemies.
Use col_hits[j] (array) for current column segment enemies.
Reset row_hits / col_hits[j] at wall or segment start.
For empty cell '0': potential = row_hits + col_hits[j].
Update max_kill.
O(m*n) time, O(n) space.

## 3. Key Points

Row_hits = enemies in current row segment.
Col_hits[j] = enemies in current column segment.
Reset row_hits or col_hits[j] at wall or segment start.
Empty cell '0': total kills = row_hits + col_hits[j].
Update max_kill.
O(m*n) time, O(n) space.

## 4. Code Implementation:


```
class Solution:
    def maxKilledEnemies(self, grid):
        if not grid or not grid[0]:
            return 0
        
        m, n = len(grid), len(grid[0])
        max_kill = 0
        col_hits = [0] * n  # Enemies in current column segments

        for i in range(m):
            row_hits = 0  # Enemies in current row segment
            for j in range(n):
                # New row segment (start or after wall)
                if j == 0 or grid[i][j-1] == 'W':
                    row_hits = 0
                    k = j
                    while k < n and grid[i][k] != 'W':
                        if grid[i][k] == 'E':
                            row_hits += 1
                        k += 1

                # New column segment (top or after wall)
                if i == 0 or grid[i-1][j] == 'W':
                    col_hits[j] = 0
                    k = i
                    while k < m and grid[k][j] != 'W':
                        if grid[k][j] == 'E':
                            col_hits[j] += 1
                        k += 1

                # Empty cell: potential kills
                if grid[i][j] == '0':
                    max_kill = max(max_kill, row_hits + col_hits[j])

        return max_kill   
```

    Time：O(n)
        
    Space: O(1)
