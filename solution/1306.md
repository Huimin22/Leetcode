## 3. Key Points

**In BFS, if the array forms a cycle and you don’t mark visited nodes, the same nodes can keep being added to the queue indefinitely, causing an infinite loop. 
Therefore, BFS must mark nodes as visited to break cycles and ensure each node is processed at most once.**


## 4. Code Implementation:


```
class Solution:
    def canReach(self, arr: List[int], start: int) -> bool:
        n = len(arr)
        queue = deque([start])
        visited = [False] * n

        while queue:
            i = queue.popleft()
            if arr[i] == 0:
                return True
            visited[i] = True
            for next_i in [i + arr[i], i - arr[i]]:
                if 0 <= next_i < n and not visited[next_i]:
                    queue.append(next_i)

        return False   

```

## 5. Complexity Analysis
    Time：O(n)
        
    Space: O(1)
