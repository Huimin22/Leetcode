## 1. Problem

 1306. Jump Game III
    
## 2. Summary

```text
- Nodes = array indices
- Neighbors = i + arr[i], i - arr[i]
- Use BFS or DFS
- Mark visited to avoid cycles
- Return True if arr[i] == 0 reached
- Otherwise False
```


## 3. Key Points

- Treat array indices as graph nodes.
- Each node i has 2 implicit neighbors: i + arr[i], i - arr[i].
- Use BFS or DFS to traverse from start.
- Mark visited nodes to avoid cycles.
- If arr[i] == 0 during traversal → return True.
- If traversal ends without reaching 0 → return False.

**In BFS, if the array forms a cycle and you don’t mark visited nodes, the same nodes can keep being added to the queue indefinitely, causing an infinite loop. 
Therefore, BFS must mark nodes as visited to break cycles and ensure each node is processed at most once.**


## 4. Code Implementation:


```
class Solution:
    def canReach(self, arr: List[int], start: int) -> bool:
        n = len(arr)
        queue = deque([start])
        visited = [False] * n

        while queue:
            i = queue.popleft()
            if arr[i] == 0:
                return True
            visited[i] = True
            for next_i in [i + arr[i], i - arr[i]]:
                if 0 <= next_i < n and not visited[next_i]:
                    queue.append(next_i)

        return False   

```

## 5. Complexity Analysis
    Time：O(n)
        
    Space: O(1)
