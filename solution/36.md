## 2. Summary

* Use 3 sets arrays: `rows[9]`, `cols[9]`, `boxes[9]`
* Iterate each cell `(r, c)`
* Skip if `'.'`
* Compute `box_index = (r//3)*3 + (c//3)`
* If `val` in `rows[r]` or `cols[c]` or `boxes[box_index]` → return False
* Else add `val` to `rows[r]`, `cols[c]`, `boxes[box_index]`
* Return True after full iteration


## 3. Key Points

* Use 3 sets arrays for rows, cols, boxes
* Skip empty cells
* Box index = `(r//3)*3 + (c//3)`
* Check if value exists in row, col, or box → invalid
* Add value to corresponding sets if not exists
* Return True if no duplicates

## 4. Code Implementation:

```
class Solution:
    def isValidSudoku(self, board: List[List[str]]) -> bool:
        rows = [set() for _ in range(9)]
        cols = [set() for _ in range(9)]
        boxes = [set() for _ in range(9)]
        for r in range(9):
            for c in range(9):
                val = board[r][c]
                if val == '.':
                    continue
                box_idx = (r//3)*3 + (c//3)
                if val in rows[r] or val in cols[c] or val in boxes[box_idx]:
                    return False
                rows[r].add(val)
                cols[c].add(val)
                boxes[box_idx].add(val)
        return True   
```
