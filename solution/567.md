## 1. Problem

567. Permutation in String
    
## 2. Summary

* Window length = len(s1)

* Loop i in `range(len(s2) - len(s1) + 1)`

* Extract window `s2[i:i+len(s1)]`

* Compare frequency (Counter or sort) with s1

* Return True if match, else False

* Key: `i_max = len(s2) - len(s1)` ✅


## 3. Key Points

* Fixed window length = len(s1)
* Slide window over s2, i in range(len(s2) - len(s1) + 1)
* Compare window frequency with s1
* Return True if match, else False

## 4. Code Implementation:

```
class Solution:
    def checkInclusion(self, s1: str, s2: str) -> bool:
        n1, n2 = len(s1), len(s2)
        if n1 > n2:
            return False

        s1_dict = Counter(s1)
        for i in range(n2-n1+1):
            win = s2[i:i+n1]
            if Counter(win) == s1_dict:
                return True
        return False   

```
