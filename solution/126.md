## 1. Problem

126. Word Ladder II
    
## 2. Summary

BFS builds shortest-path graph.

visited = nodes whose shortest distance is finalized (do not expand again).

level_visited = nodes discovered in current level (avoid duplicate enqueue, reset each level).

parents[next].append(curr) whenever next is reachable in current level (always record all shortest predecessors).

Process:
for each level:
use level_visited
generate next words
if next not in visited:
record parent
if next not in level_visited:
enqueue
add to level_visited
after level:
visited |= level_visited

After BFS:
DFS backtrack from endWord using parents to build all paths.

## 3. Key Points

### **level_visited**

> “This node has already been added to the queue in this level, so don’t enqueue it again.”

---

### **parents**

> “But I still need to record everyone who discovered this node, because all of them are valid shortest-path predecessors.”

---

### **visited**

> “This node has already been fully processed at this level (or earlier), so it should not be expanded again in future levels.”

Once a word is first discovered in BFS, its shortest distance from the start is finalized, so it will not be re-enqueued or re-expanded in later levels.

The `nw not in visited` check acts as a **guard against regression**, blocking words from previous layers to ensure the **shortest path** and prevent cycles. 

The `nw not in level_visited` check acts as a **guard against redundancy**, ensuring a word is added to the **queue only once** per layer. 

Case:
dog - cog
lot - cog  

if nw==cog in level_visited, we don't want to enqueue it and add it in level_visited again.


## 4. Code Implementation:

```
from collections import defaultdict, deque
from typing import List

class Solution:
    def findLadders(self, beginWord: str, endWord: str, wordList: List[str]) -> List[List[str]]:
        wordSet = set(wordList)
        if endWord not in wordSet:
            return []

        # child -> parents
        parents = defaultdict(list)

        queue = deque([beginWord])
        found = False

        
        visited = set()

        while queue and not found:
            level_visited = set()

            for _ in range(len(queue)):
                word = queue.popleft()

                for i in range(len(word)):
                    for c in 'abcdefghijklmnopqrstuvwxyz':
                        nw = word[:i] + c + word[i+1:]

                        if nw in wordSet and nw not in visited:
                            # track the path
                            parents[nw].append(word)

                            if nw not in level_visited:
                                queue.append(nw)
                                level_visited.add(nw)

                            if nw == endWord:
                                found = True

            visited.update(level_visited)

        res = []

        def dfs(word, path):
            if word == beginWord:
                res.append(path[::-1])
                return

            for p in parents[word]:
                dfs(p, path + [p])

        if found:
            dfs(endWord, [endWord])

        return res   
```
