## 1. Problem

200. Number of Islands
    
## 2. Summary

BFS

## 3. Key Points

- Each '1' encountered is a new island → increment count  
- Run BFS from (i,j) to mark all connected '1's as '0'  
- Continue scanning the entire grid  
- Return the total island count

## 4. Code Implementation:

```
from collections import deque
class Solution:
    def numIslands(self, grid: List[List[str]]) -> int:
        
        def bfs(grid, m, n):
            q = deque()
            q.append((m, n))
            grid[m][n] = '0'

            while q:
                x, y = q.popleft()
                for nx, ny in [(0, -1), (0, 1), (1, 0), (-1, 0)]:
                    dx, dy = nx + x, ny + y
                    if 0 <= dx < len(grid) and 0<= dy < len(grid[0]) and grid[dx][dy] == '1':
                        grid[dx][dy] = '0'
                        q.append((dx, dy))
        

        cnt = 0
        for i in range(len(grid)):
            for j in range(len(grid[0])):
                if grid[i][j] == '1':
                    bfs(grid, i , j)
                    cnt += 1
        return cnt   
```
