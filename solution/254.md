## 1. Problem

254. Factor Combinations
    
## 2. Summary

```python
res = []
def dfs(start, path, n):
    for f in range(start, n//2 + 1):
        if n % f == 0:
            res.append(path + [f, n//f])
            dfs(f, path + [f], n//f)
dfs(2, [], n)
return res
```

## 3. Key Points

* Each layer: `f` in `[start, n//2]`
* `if n % f == 0`: f is valid
* `res.append(path + [f, n//f])`: record combination
* `dfs(f, path+[f], n//f)`: explore further
* No `pop` needed (path is copied)
* Recursion stops automatically when no f is valid

## 4. Code Implementation:

```
from typing import List

class Solution:
    def getFactors(self, n: int) -> List[List[int]]:
        res = []

        def dfs(start, path, n):
            for f in range(start, n // 2 + 1):
                if n % f == 0:
                    res.append(path + [f, n // f])
                    dfs(f, path + [f], n // f)

        dfs(2, [], n)
        return res   

```
