## 4. Code Implementation:


```
from typing import List

class Solution:
    def getFactors(self, n: int) -> List[List[int]]:
        res = []

        def dfs(start, path, n):
            for f in range(start, n // 2 + 1):
                if n % f == 0:
                    res.append(path + [f, n // f])
                    dfs(f, path + [f], n // f)

        dfs(2, [], n)
        return res   

```
