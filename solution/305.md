## 1. Problem

305. Number of Islands II
    
## 2. Summary

- Use Union-Find to track connected islands
- Map 2D coords to 1D idx: idx = r * n + c
- parent[idx] = root of idx
- count = 0, res = []
- For each pos in positions:
    - if idx in parent: res.append(count); continue
    - parent[idx] = idx; count += 1
    - For 4 neighbors:
        - if neighbor in parent and union(idx, neighbor): count -= 1
    - res.append(count)
- find(x): return root with path compression
- union(x, y): merge if roots different, return True; else False

## 3. Key Points

* Use Union-Find to track islands
* Map 2D coords to 1D idx: idx = r * n + c
* parent[idx] stores root
* count = current islands, res = []
* For each position:

  * Skip if already land
  * Add new land → count += 1
  * Check 4 neighbors → union different roots → count -= 1
  * Append count to res
* find(x) returns root with path compression
* union(x, y) merges roots if different, returns True; else False

## 4. Code Implementation:

```
class Solution:
    def numIslands2(self, m: int, n: int, positions: list[list[int]]) -> list[int]:
        parent = {}
        count = 0
        res = []

        def find(x):
            parent.setdefault(x, x)
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]

        def union(x, y):
            px, py = find(x), find(y)
            if px != py:
                parent[px] = py
                return True
            return False

        for r, c in positions:
            idx = r * n + c
            if idx in parent:
                res.append(count)
                continue
            parent[idx] = idx
            count += 1

            for dr, dc in [(0,1),(0,-1),(1,0),(-1,0)]:
                nr, nc = r + dr, c + dc
                nidx = nr * n + nc
                if 0 <= nr < m and 0 <= nc < n and nidx in parent:
                    if union(idx, nidx):
                        count -= 1
            res.append(count)

        return res   

```
