## 1. Problem

110. Balanced Binary Tree

## 2. Summary

* postorder DFS (bottom-up)
* return height if subtree is balanced
* return -1 if unbalanced (propagate up)

Rule:

* compute left height, right height
* if either is -1 → return -1
* if abs(left - right) > 1 → return -1
* else return max(left, right) + 1

Final check:

* root DFS result != -1 → balanced
* else → not balanced

## 3. Key Points

* Postorder DFS (bottom-up)
* Return height if balanced, return -1 if unbalanced
* Compute left + right subtree heights
* If left == -1 or right == -1 → return -1
* If abs(left - right) > 1 → return -1
* Else return max(left, right) + 1
* Final: root != -1 → True, else False

## 4. Code Implementation:


```
class Solution:
    def isBalanced(self, root: Optional[TreeNode]) -> bool:
        def dfs(node):
            if not node:
                return 0
            
            left = dfs(node.left)
            if left == -1:
                return -1
            
            right = dfs(node.right)
            if right == -1:
                return -1
            
            if abs(left - right) > 1:
                return -1
            
            return max(left, right) + 1
        
        return dfs(root) != -1       
```
