## 1. Problem

235. Lowest Common Ancestor of a Binary Search Tree
    
## 2. Summary

```
BST property:
left < root < right

start at root

if p.val < root.val and q.val < root.val:
    move left

elif p.val > root.val and q.val > root.val:
    move right

else:
    root is LCA
```

## 3. Key Points

```
1. Use BST property: left < root < right.
2. If p,q < root → go left.
3. If p,q > root → go right.
4. Otherwise root is LCA (split point).
5. Stop when first split or equal to p/q.
```

## 4. Code Implementation:


```
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, x):
#         self.val = x
#         self.left = None
#         self.right = None

class Solution:
    def lowestCommonAncestor(self, root: 'TreeNode', p: 'TreeNode', q: 'TreeNode') -> 'TreeNode':
        while root:
            if p.val < root.val and q.val < root.val:
                root = root.left
            elif p.val > root.val and q.val > root.val:
                root = root.right
            else:
                return root   

```
