## 1. Problem

84. Largest Rectangle in Histogram
    
## 2. Summary

### The Core Logic
* **Monotonic Increasing Stack:** Store indices of bars.
* **Trigger:** When current bar < stack top, the stack top bar has found its **right boundary**.
* **Left Boundary:** The index currently *below* the top in the stack.
* **Sentinel Value:** Append a `0` to the end of the heights to ensure the stack is fully processed.

---

### The Template
```python
def largestRectangleArea(heights):
    heights.append(0) # Force final calculation
    stack = [-1]      # Acts as left boundary for index 0
    max_area = 0
    
    for i in range(len(heights)):
        # While current bar is shorter, pop and calculate
        while heights[i] < heights[stack[-1]]:
            h = heights[stack.pop()]
            w = i - stack[-1] - 1
            max_area = max(max_area, h * w)
        
        stack.append(i)
        
    return max_area
```

---

### Key Formulas
* **Height ($h$):** `heights[popped_index]`
* **Width ($w$):** `current_index - new_stack_top - 1`
* **Area ($A$):** $A = h \times w$


## 3. Key Points

### Key Points: Monotonic Stack 

* **Objective:** Find the largest area where each bar `i` is the **minimum height**.
* **Data Structure:** Use a **Monotonic Increasing Stack** to store indices.
* **The Sentinel:** Append a **0** to the input array to flush the stack at the end.
* **The Pop Trigger:** Pop when `heights[current]` < `heights[stack.top]`.
* **Area Calculation:**
    * **Height:** The height of the popped index.
    * **Width:** The distance between the `current` index and the index *now* at the top of the stack ($i - stack.top - 1$).

## 4. Code Implementation:


```
class Solution:
    def largestRectangleArea(self, heights: List[int]) -> int:
        stack = []
        max_area = 0
        heights = [0] + heights + [0]

        for i, h in enumerate(heights):
            while stack and heights[stack[-1]] > h:
                H = heights[stack.pop()]
                W = i - stack[-1] - 1
                max_area = max(max_area, H * W)
            stack.append(i)

        return max_area   
```

## 5. Complexity Analysis

* Time Complexity: $O(n)$ — Each element is pushed and popped exactly once.
* Space Complexity: $O(n)$ — Required for the stack.
