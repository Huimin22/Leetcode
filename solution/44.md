## 1. Problem

44. Wildcard Matching
    
## 2. Summary

* pattern `p`, string `s`
* `*` = match any sequence (including empty)
* `?` = match single char

Greedy + backtrack:

* two pointers: `i` (s), `j` (p)
* track `star = -1`, `match = -1`
* if chars match or `?`: i++, j++
* if `*`: star = j, match = i, j++
* else mismatch:

  * if star != -1: j = star + 1, match++, i = match
  * else return False
* after loop: remaining p must be all `*`

DP view (alt):

* `dp[i][j]`: s[:i] matches p[:j]
* transitions:

  * char or `?`: dp[i-1][j-1]
  * `*`: dp[i][j-1] or dp[i-1][j]

## 3. Key Points

* `?` matches single char
* `*` matches empty or any sequence
* Greedy matching with backtracking
* Track `star` position and last match in `s`
* On mismatch: backtrack to last `*`, expand match in `s`
* After scan: remaining `p` must be all `*`
* Time: O(n), Space: O(1) (greedy)
* DP alternative: `dp[i][j]` match prefix, `*` = skip or use char

Confused points 

* `*` ≠ automatic match success, it is variable-length matching (0~n)
* `*` first assumes empty match, mismatch triggers expansion by consuming more `s`
* `star` stores last `*` position in `p`
* `match` stores corresponding position in `s` when `*` is used
* mismatch handling = backtrack to last `*`, extend its match by +1 char
* failure case: no previous `*` and mismatch → False
* failure case: `i == len(s)` but `p` still has non-* chars → False
* remaining `p` after `s` ends must be all `*` only
* `*` may still fail if all possible extensions are exhausted and no alignment works

How these two while loops work:

First while (main loop):

* Iterates through string `s` character by character
* Matches `s` with pattern `p` simultaneously
* Handles three cases:

  * Direct match or `?`
  * Encounter `*` → record its position (`star`) and current `s` index (`match`)
  * Mismatch → backtrack to last `*` and expand its match
* Core purpose: ensure the entire `s` is processed

---

Second while (cleanup loop):

```python
while j < len(p) and p[j] == '*':
    j += 1
```

* Runs after `s` is fully matched (`i == len(s)`)
* Checks remaining part of `p`
* Only valid remaining characters can be `*`
* Because `*` can match an empty string
* Skips trailing consecutive `*`

---

Final check:

```text
j == len(p)
```

Meaning:

* The entire pattern `p` must also be fully consumed
* No remaining non-`*` characters allowed

---

One-line summary:

* First while: matches `s` with backtracking over `*`
* Second while: removes trailing `*` in `p` and verifies full match completion

Mismatch code:

On mismatch, backtrack to the most recent `*`, then incrementally expand the `*` coverage (`match++`) to consume more characters from `s`, until either a valid match is found or `s` is fully exhausted.

## 4. Code Implementation:


```

class Solution:
    def isMatch(self, s: str, p: str) -> bool:
        i = j = 0
        star = -1
        match = 0

        while i < len(s):
            if j < len(p) and (p[j] == s[i] or p[j] == '?'):
                i += 1
                j += 1
            elif j < len(p) and p[j] == '*':
                star = j
                match = i
                j += 1
            elif star != -1:
                j = star + 1
                match += 1
                i = match
            else:
                return False

        while j < len(p) and p[j] == '*':
            j += 1

        return j == len(p)

```
