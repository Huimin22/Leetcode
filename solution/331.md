## 1. Problem

331. Verify Preorder Serialization of a Binary Tree
    
## 2. Summary

similar problem: lc 297

```
slots = 1
for x in preorder:
slots -= 1
if slots < 0: return False
if x != '#': slots += 2
return slots == 0
```

## 3. Key Points

slot model:

* slot = current number of available null child positions in preorder construction
* init: slots = 1 (root position)

process each token:

* node: slots = slots - 1 + 2
* '#': slots = slots - 1

rules:

* slots < 0 → invalid
* end slots == 0 → valid

key idea:

* preorder is a linear consumption of structure
* slots are global (not left/right separated)
* each token updates slots immediately, sequentially (no batching, no subtree partition)
* ‘#’ consumes one slot only, does not generate new slots

## 4. Code Implementation:


```
class Solution:
    def isValidSerialization(self, preorder: str) -> bool:
        slots = 1
        for x in preorder.split(','):
            slots -= 1
            if slots < 0:
                return False
            if x != '#':
                slots += 2
        return slots == 0   
```

## 5. Complexity Analysis
    Time：O(n)
        
    Space: O(1)
