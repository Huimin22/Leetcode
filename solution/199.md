## 1. Problem

199. Binary Tree Right Side View
    
## 2. Summary

BFS level order

```
queue = [root]

while queue:
    size = len(queue)
    for i in range(size):
        node = pop
        if i == size - 1:
            add node.val
        push left, right
```

## 3. Key Points

```text
BFS:
- level order traversal
- for each level: iterate size
- take last node (i == size - 1)
- append to result

DFS:
- right-first traversal
- if depth == len(res): append node.val
- ensure first visit per level only
```

## 4. Code Implementation:


```
class Solution:
    def rightSideView(self, root: Optional[TreeNode]) -> List[int]:
        if not root:
            return []
    
        q = deque([root])
        res = []
        
        while q:
            size = len(q)
            for i in range(size):
                node = q.popleft()
                if i == size - 1:
                    res.append(node.val)
                if node.left:
                    q.append(node.left)
                if node.right:
                    q.append(node.right)
        
        return res   
```
