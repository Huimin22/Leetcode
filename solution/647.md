## 1. Problem

647. Palindromic Substrings
    
## 2. Summary

```text
count = 0
for i in 0..n-1:
    expand(i, i)     # odd
    expand(i, i+1)   # even

function expand(l, r):
    while l>=0 and r<n and s[l]==s[r]:
        count++
        l--
        r++
return count
```

* center expand, odd & even
* count every palindrome, no storage

## 3. Key Points

* Use center expansion or DP.
* Each char and each pair of chars can be a center.
* Expand around center, count++ for every palindrome.
* Odd and even length both considered.
* No need to store substrings, only count.
* Time O(n²), space O(1) for center expansion.



## 4. Code Implementation:


```
 class Solution:
    def countSubstrings(self, s: str) -> int:
        res = 0
        def isPali(s, left, right, cnt):
            while left >= 0 and right <= len(s)-1 and s[left] == s[right]:
                left -= 1
                right += 1
                cnt += 1
            return cnt
        
        for i in range(len(s)):
            l1 = isPali(s, i, i, 0)
            l2 = isPali(s, i, i+1, 0)
            res += l1
            res += l2
        return res  


```
