## 1. Problem

301. Remove Invalid Parentheses
    
## 2. Summary

> **Core idea:** At each DFS step, choose **delete or keep**. Delete affects only `l_rem/r_rem`, keep affects `path` and `open_count`. Non-parenthesis just append. DFS ensures all results are **minimal deletion and valid**.


## 3. Key Points

1. **Preprocess**

   * Scan the string to compute the minimum number of parentheses to remove: `l_rem`, `r_rem`.

2. **DFS(index, path, l_rem, r_rem, open_count)**

   For current character `c`:

   * **Left '('**

     * Delete → affects only `l_rem`
     * Keep → affects `path` and `open_count+1`
   * **Right ')'**

     * Delete → affects only `r_rem`
     * Keep → affects `path` and `open_count-1`, only if `open_count > 0`
   * **Non-parenthesis** → affects only `path`

3. **Termination**

   * Reached end of string
   * `l_rem == 0`, `r_rem == 0`, `open_count == 0` → valid → add to result

4. **Pruning**

   * `open_count < 0` → invalid → return
   * Do not delete more than `l_rem/r_rem`


## 4. Code Implementation:

```
class Solution:
    def removeInvalidParentheses(self, s: str) -> list[str]:
        res = set()
        
        l_rem, r_rem = 0, 0
        for c in s:
            if c == '(':
                l_rem += 1
            elif c == ')':
                if l_rem > 0:
                    l_rem -= 1
                else:
                    r_rem += 1
        
        def dfs(index, path, l_rem, r_rem, open_count):
            if index == len(s):
                if l_rem == 0 and r_rem == 0 and open_count == 0:
                    res.add(path)
                return
            
            c = s[index]
            
            if c == '(':
                if l_rem > 0:
                    dfs(index + 1, path, l_rem - 1, r_rem, open_count)
                dfs(index + 1, path + '(', l_rem, r_rem, open_count + 1)
            
            elif c == ')':
                if r_rem > 0:
                    dfs(index + 1, path, l_rem, r_rem - 1, open_count)
                if open_count > 0:
                    dfs(index + 1, path + ')', l_rem, r_rem, open_count - 1)
            else:
                dfs(index + 1, path + c, l_rem, r_rem, open_count)
        
        dfs(0, '', l_rem, r_rem, 0)
        return list(res)      

```
