## 1. Problem

283. Move Zeroes
    
## 2. Summary

Use two pointers to move all non-zero elements to the front.

## 3. Key Points

fast → scan the array
slow → position for the next non-zero element
If nums[fast] !== 0, put it at nums[slow]
Move slow forward
Fill the remaining positions with 0

## 4. Code Implementation:


```
var moveZeroes = function(nums) {
    let i = 0;
    for(let k = 0;k<nums.length;k++){
        if (nums[k] !== 0) {
            nums[i] = nums[k];
            i++;
        } 
    }

    while (i<nums.length){
        nums[i] = 0;
        i++;
    }
    
};   


```

## 5. Complexity Analysis
    Time：O(n)
        
    Space: O(1)
