## 1. Problem

141. Linked List Cycle
    
## 2. Summary

Initialize slow and fast to head
while fast != null and fast.next != null:
    slow = slow.next
    fast = fast.next.next
    if slow == fast:
        return true
return false

## 3. Key Points

* slow moves 1 step, fast moves 2 steps
* cycle exists if slow meets fast
* no cycle if fast reaches null

## 4. Code Implementation:

```
class Solution:
    def hasCycle(self, head: Optional[ListNode]) -> bool:
        slow = head
        fast = head
        while fast != None and fast.next != None:
            fast = fast.next.next
            slow = slow.next
            if slow == fast:
                return True
        return False   
```

## 5. Complexity Analysis
    Time：O(n)
        
    Space: O(1)
