## 1. Problem

45. Jump Game II
    
## 2. Summary


Greedy BFS (interval expansion)

* Track current range [start, end] = all positions reachable in current step
* Traverse i from start → end
* Update farthest = max(i + nums[i])
* When i == end:
  steps += 1
  start = end + 1
  end = farthest
* Stop when end >= last index
* Return steps

## 4. Code Implementation:


```
from typing import List

class Solution:
    def jump(self, nums: List[int]) -> int:
        steps = 0
        end = 0
        farthest = 0

        for i in range(len(nums) - 1):
            farthest = max(farthest, i + nums[i])
            
            if i == end:
                steps += 1
                end = farthest

        return steps   


```

    Time：O(n)
