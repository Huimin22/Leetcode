## 1. Problem

45. Jump Game II
    
## 2. Summary


Greedy BFS (interval expansion)

* Track current range [start, end] = all positions reachable in current step
* Traverse i from start → end
* Update farthest = max(i + nums[i])
* When i == end:
  steps += 1
  start = end + 1
  end = farthest
* Stop when end >= last index
* Return steps


## 3. Key Points

*   **`steps` (Level/Depth):** Represents the current BFS level. Each increment of 1 corresponds to taking one additional jump.
*   **`end` (Current Level Boundary):** The maximum reach of the current jump. You are exploring within the "current level" until this index is reached.
*   **`farthest` (Next Level Potential):** While traversing the current level, you identify the furthest possible point reachable from any index within it. This becomes the boundary for the next level.

## 4. Code Implementation:


```
from typing import List

class Solution:
    def jump(self, nums: List[int]) -> int:
        steps = 0
        end = 0
        farthest = 0

        for i in range(len(nums) - 1):
            farthest = max(farthest, i + nums[i])
            
            if i == end:
                steps += 1
                end = farthest

        return steps   


```

    Time：O(n)
        
    Space: O(1)
