## 1. Problem

287. Find the Duplicate Number
    
## 2. Summary

* Key idea: first meeting encodes cycle start; second phase → entry.

* Treat array as **linked list**: index → value → next index

* **Detect cycle (Floyd’s Tortoise & Hare)**

  * slow = nums[0], fast = nums[0]
  * while True:

    * slow = nums[slow]
    * fast = nums[nums[fast]]
    * if slow == fast: break

* **Find cycle entry (duplicate)**

  * slow2 = nums[0]
  * while slow != slow2:

    * slow = nums[slow]
    * slow2 = nums[slow2]
  * return slow
 

## 3. Key Points

* Treat array as linked list: index → value → next index
* Use Floyd’s cycle detection (slow=1 step, fast=2 steps) to find first meeting
* Second phase: slow from meeting, slow2 from head, 1 step each → meet at duplicate
* Time O(n), space O(1)
* First meeting encodes cycle start; second phase finds entry


* **Index as node**: each index uniquely identifies a position; a duplicate number → two different indices pointing to the same index → forms a cycle.
* **Value as pointer, index as node** → abstract the array as a linked list.


## 4. Code Implementation:


```
class Solution:
    def findDuplicate(self, nums: List[int]) -> int:
        slow = nums[0]
        fast = nums[0]
        while True:
            slow = nums[slow]
            fast = nums[nums[fast]]
            if slow == fast:
                break
        
        slow2 = nums[0]
        while slow != slow2:
            slow2 = nums[slow2]
            slow = nums[slow]
        return slow   


```
