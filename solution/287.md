## 1. Problem

287. Find the Duplicate Number
    
## 2. Summary

* Key idea: first meeting encodes cycle start; second phase → entry.

* Treat array as **linked list**: index → value → next index

* **Detect cycle (Floyd’s Tortoise & Hare)**

  * slow = nums[0], fast = nums[0]
  * while True:

    * slow = nums[slow]
    * fast = nums[nums[fast]]
    * if slow == fast: break

* **Find cycle entry (duplicate)**

  * slow2 = nums[0]
  * while slow != slow2:

    * slow = nums[slow]
    * slow2 = nums[slow2]
  * return slow

## 4. Code Implementation:


```
class Solution:
    def findDuplicate(self, nums: List[int]) -> int:
        slow = nums[0]
        fast = nums[0]
        while True:
            slow = nums[slow]
            fast = nums[nums[fast]]
            if slow == fast:
                break
        
        slow2 = nums[0]
        while slow != slow2:
            slow2 = nums[slow2]
            slow = nums[slow]
        return slow   


```

    Time：O(n)
        
    Space: O(1)
