## 1. Problem

47. Permutations II
    
## 2. Summary

1. Sort `nums` first.
2. Use backtracking with:

   * `path`
   * `used = [False] * n`
3. If `len(path) == n` → add copy to result.
4. Loop `i in range(n)`:

   * If `used[i]` → continue.
   * If `i > 0 and nums[i] == nums[i-1] and not used[i-1]` → continue. (same level duplicate)
   * Choose:

     * `used[i] = True`
     * `path.append(nums[i])`
   * Recurse.
   * Un-choose:

     * `path.pop()`
     * `used[i] = False`

Core rule:
Same level skip (`not used[i-1]`), same branch keep (`used[i-1]`).

## 4. Code Implementation:


```
class Solution:
    def permuteUnique(self, nums: List[int]) -> List[List[int]]:
        nums.sort()
        res = []
        used = [False]*len(nums)
        print(used)
        def dfs(path, used):
            if len(path) == len(nums):
                res.append(path[:])
            for i in range(len(nums)):
                if i > 0 and nums[i] == nums[i-1] and not used[i-1]:
                    continue
                if used[i] == True:
                    continue
                used[i] = True
                path.append(nums[i])
                dfs(path, used)
                path.pop()
                used[i] = False
        dfs([], used)
        return res  
```

Mistake:
Used `not used[i]` instead of `not used[i-1]` in the duplicate pruning condition.

Why wrong:
`used[i]` checks current element state, which is meaningless for dedup.
Duplicate pruning depends on whether the previous identical number was used in the same tree level.
If `nums[i] == nums[i-1]` and `used[i-1] == False`, it means we are at the same level and already skipped the previous identical choice — choosing this one would create a duplicate branch.

Correct logic:
`used[i-1]` distinguishes same-level vs deeper-level usage.
