## 1. Problem

205. Isomorphic Strings
    
## 2. Summary

```python
def isIsomorphic(s, t):
    s2t, t2s = {}, {}
    for cs, ct in zip(s, t):
        if s2t.get(cs, ct) != ct or t2s.get(ct, cs) != cs:
            return False
        s2t[cs] = ct
        t2s[ct] = cs
    return True
```

## 3. Key Points

* Two dicts: `s→t` and `t→s`
* Check mapping consistency
* Update dicts each step
* Return False if conflict, else True
