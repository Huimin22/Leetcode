## 4. Code Implementation:


```
class Solution:
    def isIsomorphic(self, s: str, t: str) -> bool:
        s2t, t2s = {}, {}
        for cs, ct in zip(s, t):
            if s2t.get(cs, ct) != ct or t2s.get(ct, cs) != cs:
                return False
            s2t[cs] = ct
            t2s[ct] = cs
        return True   
```
