### Histogram Template (84)

```
use monotonic increasing stack (store indices)

add sentinel: [0] + heights + [0]

for i in heights:
    while stack and heights[stack[-1]] > heights[i]:
        h = pop height
        left = stack[-1]
        right = i
        width = right - left - 1
        area = h * width
        update max
    push i
```

---

### Key Rules

```
- stack keeps increasing heights
- pop when current < stack top
- each pop = final best rectangle for that height
- width = (right smaller - left smaller - 1)
```

---

```
85 = build histogram per row + run 84 monotonic stack max rectangle
```

## 4. Code Implementation:

```
class Solution:
    def maximalRectangle(self, matrix: List[List[str]]) -> int:
        if not matrix or not matrix[0]:
            return 0

        n = len(matrix[0])
        height = [0] * n
        res = 0

        def largest_rectangle(heights):
            stack = []
            max_area = 0
            heights = [0] + heights + [0]

            for i, h in enumerate(heights):
                while stack and heights[stack[-1]] > h:
                    H = heights[stack.pop()]
                    W = i - stack[-1] - 1
                    max_area = max(max_area, H * W)
                stack.append(i)

            return max_area

        for row in matrix:
            for j in range(n):
                if row[j] == '1':
                    height[j] += 1
                else:
                    height[j] = 0

            res = max(res, largest_rectangle(height))

        return res   
```
