## 1. Problem

169. Majority Element
    
## 2. Summary

```
candidate = count = 0
for num in nums:
    if count == 0: candidate = num
    count += 1 if num == candidate else -1
return candidate
```

## 3. Key Points

```
same → count+1, different → count-1, count==0 → new candidate
majority > n/2 → cannot be fully canceled
```
## 4. Code Implementation:


```
class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        can = 0
        cnt = 0
        for num in nums:
            if cnt == 0:
                can = num
            if num == can:
                cnt += 1
            else:
                cnt -= 1
        return can   
```

## 5. Complexity Analysis
    Time：O(n)
        
    Space: O(1)
