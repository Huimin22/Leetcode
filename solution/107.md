## 1. Problem

107. Binary Tree Level Order Traversal II
    
## 2. Summary

refer LC 102.

Zigzag → normal level order, remove zigzag flag, append each level, reverse result at end.

* Use deque only if you want to avoid final reverse.
* Traverse level by level, left to right.
* Append each level to result.
* Return `res[::-1]` or `res.reverse()`.

## 3. Key Points

* Traverse tree level by level, left to right.
* Collect node values per level.
* Append each level to result list.
* Reverse result at end to get bottom-up order.
* Optional: use deque.appendleft to avoid final reverse.

## 4. Code Implementation:

```
class Solution:
    def levelOrderBottom(self, root: Optional[TreeNode]) -> List[List[int]]:
        if not root:
            return []
        
        q = deque([root])
        res = []

        while q:
            n = len(q)
            level = []
            for _ in range(n):
                cur_n = q.popleft()
                level.append(cur_n.val)

                if cur_n.left:
                    q.append(cur_n.left)
                if cur_n.right:
                    q.append(cur_n.right)
            
            res.append(level)
        res.reverse()
        return res   
```

## 5. Complexity Analysis
    Time：O(n)
        
    Space: O(1)
