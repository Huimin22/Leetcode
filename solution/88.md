## 1. Problem

88. Merge Sorted Array
    
## 2. Summary

Use two pointers to merge the arrays from the end.

## 3. Key Points

i → last valid element in nums1
j → last element in nums2
k → last position in nums1
Compare nums1[i] and nums2[j]
Put the larger one at nums1[k]
Move pointers backward
Fill remaining nums2 elements if needed

## 4. Code Implementation:


```
var merge = function(nums1, m, nums2, n) {
    let i = m-1;
    let j = n-1;
    let k = m+n-1;
    while (i >= 0 && j >= 0) {
        if(nums1[i] > nums2[j]) {
            nums1[k] = nums1[i];
            i--;
            k--;
        } else {
            nums1[k] = nums2[j];
            j--;
            k--;
        }
    }

    while (j>=0) {
        nums1[k] = nums2[j];
        j--;
        k--;
    }   
};   


```

## 5. Complexity Analysis
    Time：O(n)
        
    Space: O(1)
