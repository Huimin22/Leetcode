64. Minimum Path Sum
    
## 2. Summary

dp[i][j] = max square side ending at (i,j)
if matrix[i][j] == '1':

## 3. Key Points

* Left + top → edges
* Top-left → interior
* min of three → max square side


## 4. Code Implementation:


```
class Solution:
    def minPathSum(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        dp = [[0] * n for _ in range(m)]
        
        dp[0][0] = grid[0][0]
        for j in range(1, n):
            dp[0][j] = dp[0][j-1] + grid[0][j]
        
        for i in range(1, m):
            dp[i][0] = dp[i-1][0] + grid[i][0]
        
        for i in range(1, m):
            for j in range(1, n):
                dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]
        
        return dp[m-1][n-1]   
```
