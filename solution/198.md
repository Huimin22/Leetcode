## 1. Problem

198. House Robber
    
## 2. Summary

DP

* **Transition:** `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`

## 3. Key Points

**Template**

* **State:** `dp[i] = max money up to house i`
* **Transition:** `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`
* **Init:** `dp[0]=nums[0]`, `dp[1]=max(nums[0], nums[1])`
* **Answer:** `dp[n-1]`
* **Edge:** if `n==0 → 0`, if `n==1 → nums[0]`

**Template Code:**

```python
if not nums:
    return 0
n = len(nums)
if n == 1:
    return nums[0]

dp = [0]*n
dp[0] = nums[0]
dp[1] = max(nums[0], nums[1])

for i in range(2, n):
    dp[i] = max(dp[i-1], dp[i-2] + nums[i])

return dp[n-1]
```

* DP problem, adjacent houses cannot both be robbed
* `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`
* Init: `dp[0]=nums[0]`, `dp[1]=max(nums[0], nums[1])`
* Edge: `n==0 → 0`, `n==1 → nums[0]`
* Answer: `dp[n-1]`
* Can optimize space to O(1) using two variables

## 4. Code Implementation:

```
class Solution:
    def rob(self, nums: List[int]) -> int:
        if not nums:
            return 0

        n = len(nums)
        if n == 1:
            return nums[0]

        dp = [0]*n
        dp[0] = nums[0]
        dp[1] = max(nums[0], nums[1])

        for i in range(2, n):
            dp[i] = max(dp[i-1], dp[i-2] + nums[i])
        return dp[n-1]  

```

**Second**

* `dp[i]`, `dp[i-1]`, `nums[i]` are safe within `0..n-1`.
