## 1. Problem

347. Top K Frequent Elements
    
## 2. Summary

Use Bucket

* Count elements’ frequency → `Counter`
* Build buckets: index = frequency, value = elements list
* Traverse buckets from high → low
* Collect elements until K reached

## 3. Key Points

* Use `Counter` to count element frequency
* Bucket list: index = frequency, store elements
* Traverse buckets from high to low
* Collect top K elements

## 4. Code Implementation:

```
class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        freq = Counter(nums)
        n = len(nums)
        bucket = [[] for _ in range(n+1)]

        for num, f in freq.items(): 
            bucket[f].append(num)

        res = []

        for i in range(n, -1, -1):
            for num in bucket[i]:
                res.append(num)
                if len(res) == k:
                    return res   
```

## 5. Complexity Analysis
    Time：O(n)
        
    Space: O(1)
