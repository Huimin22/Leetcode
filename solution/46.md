## 1. Problem

46. Permutations
    
## 2. Summary

```python
res = []
used = [False]*len(nums)

def dfs(path, used):
    if len(path) == len(nums):
        res.append(path[:])
        return
    for i in range(len(nums)):
        if used[i]:
            continue
        used[i] = True
        path.append(nums[i])
        dfs(path, used)
        path.pop()
        used[i] = False

dfs([], used)
return res
```

**Quick memory**:

* `path` = current selection
* `used` = marks chosen numbers
* DFS = explore all paths → when `len(path)==n` collect → backtrack

No extra words, just “choose → recurse → backtrack → collect.”


## 3. Key Points

* DFS / backtrack
* `path` = current sequence
* `used[i]` = number used in current path
* Recurse all unused numbers
* If `len(path) == n` → append path copy to res
* Backtrack: pop + reset used

## 4. Code Implementation:

```
class Solution:
    def permute(self, nums: List[int]) -> List[List[int]]:
        res = []
        used = [False]*len(nums)
    

        def dfs(path, used):
            if len(path) == len(nums):
                res.append(path[:])
                return 
            for i in range(len(nums)):
                if used[i]:
                    continue
                used[i] = True
                path.append(nums[i])
                dfs(path, used)
                path.pop()
                used[i] = False
        
        dfs([], used)

        return res    
```

## 8. Note

**Mistake**

* `path.append([nums[i]])` → creates nested list; should append number directly
* Confused necessity of `used` → needed to track numbers already in current path
* Thought DFS collects at every node → actually only collects when `len(path) == n`
* Considered defining `used` inside dfs → would reset state each recursion; must define outside or before dfs call
