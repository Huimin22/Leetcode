maxReach = 0
for i, jump in enumerate(nums):
    if i > maxReach: 
        return False
    maxReach = max(maxReach, i + jump)

* Maintain `maxReach` = farthest reachable index
* If current index > `maxReach` → can't reach → False
* Otherwise update `maxReach`
* Finish loop → True

## 3. Key Points

* `maxReach` tracks farthest reachable index
* If `i > maxReach` → return False
* Update `maxReach = max(maxReach, i + nums[i])`
* Finish loop → return True

## 4. Code Implementation:


```
class Solution:
    def canJump(self, nums: List[int]) -> bool:
        maxR = 0
        for i, jump in enumerate(nums):
            if i > maxR:
                return False
            maxR = max(maxR, i + jump)
        return True   
```
