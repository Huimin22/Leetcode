## 1. Problem

188. Best Time to Buy and Sell Stock IV
    
## 2. Summary

“No stock today: yesterday had none, or sold today;

Stock today: yesterday held, or bought today.”


Base case (day 0):

k = 0:
not holding → 0
holding → impossible → -inf

k ≥ 1:
not holding → 0
holding → bought today → -prices[0]


```python
def maxProfit(k, prices):
    if not prices: return 0
    n = len(prices)
    if k >= n//2:  # unlimited transactions
        return sum(max(prices[i+1]-prices[i],0) for i in range(n-1))
    
    dp = [[0, -float('inf')] for _ in range(k+1)]
    for price in prices:
        for t in range(1, k+1):
            dp[t][0] = max(dp[t][0], dp[t][1] + price)
            dp[t][1] = max(dp[t][1], dp[t-1][0] - price)
    return dp[k][0]
```

## 3. Key Points

* DP[t][0/1] = max profit with t transactions, 0=not hold, 1=hold
* If k large → treat as unlimited
* Update in order: sell then buy
* Return dp[k][0]

---

### 1️⃣ Structure (shape)

It is a **3D array**:

```
dp[n][max_k+1][2]
```

Meaning:

* 1st dimension `i`: day `i`
* 2nd dimension `j`: at most `j` transactions
* 3rd dimension `0/1`: holding state

  * `0` → not holding stock
  * `1` → holding stock

---

### 2️⃣ What initialization looks like

Assume:

```
n = 2
max_k = 2
```

Then `dp` is:

```
[
  [ [0,0], [0,0], [0,0] ],   # day 0
  [ [0,0], [0,0], [0,0] ]    # day 1
]
```

---

### 3️⃣ Inside each cell

```
dp[i][j] = [0, 0]
```

Meaning:

```
dp[i][j][0] = 0   # not holding
dp[i][j][1] = 0   # holding
```

## 4. Code Implementation:


```
class Solution:
    def maxProfit(self, k: int, prices: List[int]) -> int:
        if not prices:
            return 0
        
        n = len(prices)
        max_k = k
        dp = [[[0]*2 for _ in range(max_k+1)] for _ in range(n)] 
        
        for j in range(1, max_k+1):
            dp[0][j][0] = 0
            dp[0][j][1] = -prices[0]
        dp[0][0][0] = 0
        dp[0][0][1] = float('-inf')
        
        for i in range(1, n):
            for j in range(1, max_k+1):
                dp[i][j][0] = max(dp[i-1][j][0], dp[i-1][j][1]+prices[i])
                dp[i][j][1] = max(dp[i-1][j][1], dp[i-1][j-1][0]-prices[i])
        
        return max(dp[n-1][j][0] for j in range(k+1))

```
