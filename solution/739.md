## 1. Problem

739. Daily Temperatures
    
## 2. Summary

* Use a stack to store **indices** of days waiting for a warmer temperature
* Traverse temperatures left to right
* While stack not empty and `current_temp > temperatures[stack[-1]]`:
* Pop index, set `answer[index] = current_index - index`
* Push current index onto stack
* Remaining indices in stack → answer = 0

## 3. Key Points

* Stack stores indices of unresolved days
* Traverse temperatures left to right
* While stack and `current > temperatures[stack[-1]]`: pop and update answer
* Push current index to stack
* Remaining stack → answer = 0

## 4. Code Implementation:

```
class Solution:
    def dailyTemperatures(self, temperatures: List[int]) -> List[int]:
        n = len(temperatures)
        answer = [0] * n
        stack = []

        for i, temp in enumerate(temperatures):
            while stack and temp > temperatures[stack[-1]]:
                prev_index = stack.pop()
                answer[prev_index] = i - prev_index
            stack.append(i)

        return answer   

```

## 5. Complexity Analysis
    Time：O(n)
        
    Space: O(1)
