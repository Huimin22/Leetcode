## Problem: Build Obstacles and Check Blocks

Input: An array of operations `operations`.

There are two types of operations:

- `[1, x]`: Build an obstacle at coordinate `x`. It is guaranteed that no obstacle currently exists at `x`.
- `[2, x, size]`: Check whether a block centered at `x`, extending `size` units in both directions, can be built without overlapping any obstacles.

For type 2, check the interval:

\\[ [x-size,\ x+size] \\]

- Return `"1"` if there are no obstacles in this interval.
- Return `"0"` if at least one obstacle exists in this interval.

Note: Type 2 only checks whether the block can be built. It does not actually build the block.

Output: Return a binary string containing the results of all type 2 operations, in order.

### Example

```
operations = [
  [1, 2],
  [1, 6],
  [2, 4, 2],
  [2, 3, 1],
  [2, 10, 2]
]
```

| Operation    | Interval checked    | Result |
| ------------ | ------------------- | ------ |
| `[1, 2]`     | Build obstacle at 2 | —      |
| `[1, 6]`     | Build obstacle at 6 | —      |
| `[2, 4, 2]`  | `[2, 6]`            | `0`    |
| `[2, 3, 1]`  | `[2, 4]`            | `0`    |
| `[2, 10, 2]` | `[8, 12]`           | `1`    |

Output:

```
"001"
```
