## 1. Problem

## Problem: Build Obstacles and Check Blocks

Input: An array of operations `operations`.

Given an infinite integer number line, you would like to build some blocks and obstacles on it. Specifically, you have to implement code which supports two types of operations:

\- `[1, x]` - builds an obstacle at coordinate `x` along the number line. It is guaranteed that coordinate `x` does not contain any obstacles when the operation is performed.

\- `[2, x, size]` - checks whether it's possible to build a block centered on `x` and extending `size-1` units in each direction. For example, for `size = 2` and `x = 0`, it will check coordinates `-1` through `1` on the number line for obstacles. Produces `"1"` if it is possible, i.e., if there are no obstacles at the specified coordinates, and produces `"0"` otherwise.

Please note that this operation does not actually build the block. It only checks whether a block can be built.

Given an array of operations containing both types of operations above, your task is to return a binary string representing the outputs for all `[2, x, size]` operations.

Note: Type 2 only checks whether the block can be built. It does not actually build the block.

Output: Return a binary string containing the results of all type 2 operations, in order.

### Example

```
operations = [
  [1, 2],
  [1, 6],
  [2, 4, 2],
  [2, 3, 1],
  [2, 10, 2]
]
```

| Operation    | Interval checked    | Result |
| ------------ | ------------------- | ------ |
| `[1, 2]`     | Build obstacle at 2 | —      |
| `[1, 6]`     | Build obstacle at 6 | —      |
| `[2, 4, 2]`  | `[2, 6]`            | `0`    |
| `[2, 3, 1]`  | `[2, 4]`            | `0`    |
| `[2, 10, 2]` | `[8, 12]`           | `1`    |

Output:

```
"001"
```

## 4. Code Implementation:

TreeMap
```
def solution(operations):
    points = set()

    for o in operations:
        if o[0] == 1:
            points.add(o[1])
        else:
            start = o[1] - o[2] + 1
            end = o[1] + o[2] - 1
            points.add(start)
            points.add(end)

    sorted_points = sorted(list(points))

    mapping = {}
    for i, p in enumerate(sorted_points, 1):
        mapping[p] = i

    n = len(sorted_points)
    f = [0] * (n + 1)
    answer = []

    for o in operations:
        if o[0] == 1:
            mp = mapping[o[1]]
            while mp <= n:
                f[mp] += 1
                mp += mp & -mp
        else:
            mstart = mapping[o[1] - o[2] + 1]
            mend = mapping[o[1] + o[2] - 1]

            obs = 0

            while mend > 0:
                obs += f[mend]
                mend -= mend & -mend

            mstart -= 1
            while mstart > 0:
                obs -= f[mstart]
                mstart -= mstart & -mstart

            if obs ==0:
                answer.append("1")
            else:
                answer.append("0")

    return "".join(answer)

```
