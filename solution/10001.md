## 1. Problem
Largest X Shape in a Binary Matrix

Given an \\(m \times n\\) binary matrix `matrix` consisting of `0`s and `1`s, find the center coordinates of the largest X shape.

An X shape is centered at a cell containing `1` and extends diagonally in all four directions: top-left, top-right, bottom-left, and bottom-right. All cells along the four diagonal arms must contain `1`s, and all four arms must have equal lengths.

The size of an X shape is defined as the number of steps it extends outward from the center, excluding the center cell.

Return the coordinates `[row, col]` of the center of the largest X shape. If multiple X shapes have the same maximum size, return any one of their centers. If no valid X shape exists, return `[-1, -1]`.

Example 1:

```
matrix = [    [1, 0, 0, 0, 1],    [0, 1, 0, 1, 0],    [0, 0, 1, 0, 0],    [0, 1, 0, 1, 0],    [1, 0, 0, 0, 1]]
```

Output: `[2, 2]`

Explanation: The largest X is centered at `[2, 2]` and extends two steps diagonally in each of the four directions.

Constraints:

- \\(1 \le m, n \le 500\\)
- `matrix[i][j]` is either `0` or `1`.

```
def solution(matrix):
    answer = (0, 0)
    best_length = 0

    m = len(matrix)
    n = len(matrix[0])

    for i in range(m):
        for j in range(n):
            if matrix[i][j] == 1:

                max_length = min(
                    i + 1,
                    j + 1,
                    m - i,
                    n - j
                )

                if max_length <= best_length:
                    continue

                check_length = 1

                while check_length <= max_length:
                    if (
                        matrix[i - check_length + 1][j - check_length + 1] == 1
                        and matrix[i - check_length + 1][j + check_length - 1] == 1
                        and matrix[i + check_length - 1][j - check_length + 1] == 1
                        and matrix[i + check_length - 1][j + check_length - 1] == 1
                    ):
                        check_length += 1
                    else:
                        break

                if check_length - 1 > best_length:
                    best_length = check_length - 1
                    answer = (i, j)

    return answer
```

```
def largest_x(matrix):
    m, n = len(matrix), len(matrix[0])

    tl = [[0] * n for _ in range(m)]
    tr = [[0] * n for _ in range(m)]
    bl = [[0] * n for _ in range(m)]
    br = [[0] * n for _ in range(m)]

    # 1. Top-left: 左上 -> 右下
    for r in range(m):
        for c in range(n):
            if matrix[r][c] == 1:
                tl[r][c] = 1
                if r > 0 and c > 0:
                    tl[r][c] += tl[r - 1][c - 1]

    # 2. Top-right: 右上 -> 左下
    for r in range(m):
        for c in range(n - 1, -1, -1):
            if matrix[r][c] == 1:
                tr[r][c] = 1
                if r > 0 and c < n - 1:
                    tr[r][c] += tr[r - 1][c + 1]

    # 3. Bottom-left: 左下 -> 右上
    for r in range(m - 1, -1, -1):
        for c in range(n):
            if matrix[r][c] == 1:
                bl[r][c] = 1
                if r < m - 1 and c > 0:
                    bl[r][c] += bl[r + 1][c - 1]

    # 4. Bottom-right: 右下 -> 左上
    for r in range(m - 1, -1, -1):
        for c in range(n - 1, -1, -1):
            if matrix[r][c] == 1:
                br[r][c] = 1
                if r < m - 1 and c < n - 1:
                    br[r][c] += br[r + 1][c + 1]

    # 5. Find the largest X and its center
    max_size = 0
    center = [-1, -1]

    for r in range(m):
        for c in range(n):
            size = min(
                tl[r][c],
                tr[r][c],
                bl[r][c],
                br[r][c]
            )

            if size > max_size:
                max_size = size
                center = [r, c]

    return center
```
