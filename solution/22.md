## 1. Problem

22. Generate Parentheses
    
## 2. Summary

```python
dfs(path, open, close):
    if len(path) == 2*n: res.append(path); return
    if open < n: dfs(path+'(', open+1, close)
    if close < open: dfs(path+')', open, close+1)

dfs("", 0, 0)
```

**Concept:** DFS = explore paths, intermediate = current state, prune illegal, collect at leaf, backtrack.


## 3. Key Points

* DFS explores all possible paths.
* Intermediate state = current path and counts.
* Prune dead ends (illegal moves).
* Leaf node = complete valid result, add to output.
* Backtrack to explore other branches.

## 4. Code Implementation:


```
class Solution:
    def generateParenthesis(self, n: int) -> List[str]:
        res = []

        def dfs(path, open_cnt, clo_cnt):
            if len(path) == 2*n:
                res.append("".join(path))
            if open_cnt < n :
                path.append('(')
                dfs(path, open_cnt+1, clo_cnt)
                path.pop()
            if clo_cnt < open_cnt:
                path.append(')')
                dfs(path, open_cnt, clo_cnt+1)
                path.pop()
        dfs([], 0, 0)
        return res
   
```

    Time：O(n)
