## 1. Problem

146. LRU Cache
    
## 2. Summary

* O(1) get + O(1) put

* Use **HashMap + Doubly Linked List**

* HashMap: `key -> node`

* Doubly Linked List: maintain usage order

* `head.next` = LRU

* `tail.prev` = MRU

* Access node → remove + add_to_tail (mark MRU)

* Insert new node → add_to_tail

* If full → remove head.next + delete from map

* List size == Map size

* Every node in map must be in list

* Move = remove + insert (no direct move operation)

## 3. Key Points



  ### Core Idea

* dict = fast lookup
* list = maintain order
* move accessed node to MRU
* evict from LRU side

### Core Operations

#### Node initialization:
key, value, prev, next.

#### LRU initialization:
dict + doubly linked list + capacity (capacity tracks dictionary size; the linked list has dummy nodes so we don’t use its length).

#### _add method:
Idea: insert the newest (MRU) node at the tail.
Code: find the tail node’s prev and next nodes, then create new connections:

* node.prev connects with pren (two-way link)
* node.next connects with nxt (two-way link)

####  _remove method:
Find the node’s prev and next nodes, then connect these two nodes together with a two-way link.

#### get(key) method:
Check whether the key is in cache.
If yes, get the node directly from the dictionary, update its position in the linked list (remove the node first, then add it to the tail), and return `node.val`.

#### put(key, val) method:
Check whether the key is in cache.

* If yes: get the node from the dictionary, update `val`, and update its position in the linked list.
* If not: check the dictionary size. If it exceeds the capacity, find the LRU node (the node after `head`) in the linked list, remove it from the linked list, and delete `node.key` from the dictionary.

After that, create a new node, add it to the dictionary, and update the linked list by adding the new node to the tail.

**Add to tail (mark MRU)**

```
prev = tail.prev
prev.next = node
node.prev = prev
node.next = tail
tail.prev = node
```

**Remove node**

```
prev = node.prev
next = node.next
prev.next = next
next.prev = prev
```

## 4. Code Implementation:

```
class Node:
    def __init__(self, key=0, value=0):
        self.key = key
        self.val = value
        self.next = None
        self.prev = None


class LRUCache:

    def __init__(self, capacity: int):
        self.cap = capacity
        self.cache = {}

        self.head = Node()
        self.tail = Node()

        self.head.next = self.tail
        self.tail.prev = self.head


    def addtail(self, node):
        prevn, nextn = self.tail.prev, self.tail
        node.prev = prevn
        prevn.next = node
        node.next = nextn
        nextn.prev = node


    def remove(self, node):
        prevn, nextn = node.prev, node.next
        prevn.next = nextn
        nextn.prev = prevn


    def get(self, key: int) -> int:
        if key not in self.cache:
            return -1

        node = self.cache[key]
        self.remove(node)
        self.addtail(node)

        return node.val


    def put(self, key: int, value: int) -> None:

        if key in self.cache:
            node = self.cache[key]
            node.val = value
            self.remove(node)
            self.addtail(node)

        else:
            if len(self.cache) >= self.cap:
                lru_n = self.head.next
                self.remove(lru_n)
                del self.cache[lru_n.key]

            node = Node(key, value)
            self.cache[key] = node
            self.addtail(node)
```
