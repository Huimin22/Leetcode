## 1. Problem

146. LRU Cache
    
## 2. Summary

### Core Idea

* dict = fast lookup
* list = maintain order
* move accessed node to MRU
* evict from LRU side

**HashMap + Doubly Linked List = LRU Template**


**Goal:**
O(1) get + O(1) put
Evict least recently used when full.

---

### Data Structures

* `dict: key -> node`
* `double linked list` (order by usage)
* `head <-> ... <-> tail` (dummy nodes)

Rule:

* `head.next` = LRU
* `tail.prev` = MRU

---

### Core Operations

**Remove node**

```
prev = node.prev
next = node.next
prev.next = next
next.prev = prev
```

**Add to tail (mark MRU)**

```
prev = tail.prev
prev.next = node
node.prev = prev
node.next = tail
tail.prev = node
```

---

### get(key)

```
if key not in cache: return -1
node = cache[key]
remove(node)
add_to_tail(node)
return node.val
```

---

### put(key, val)

```
if key in cache:
    node = cache[key]
    node.val = val
    remove(node)
    add_to_tail(node)
else:
    if size == capacity:
        lru = head.next
        remove(lru)
        delete cache[lru.key]
    node = new Node
    cache[key] = node
    add_to_tail(node)
```

## 3. Key Points


* O(1) get + O(1) put

* Use **HashMap + Doubly Linked List**

* HashMap: `key -> node`

* Doubly Linked List: maintain usage order

* `head.next` = LRU

* `tail.prev` = MRU

* Access node → remove + add_to_tail (mark MRU)

* Insert new node → add_to_tail

* If full → remove head.next + delete from map

* List size == Map size

* Every node in map must be in list

* Move = remove + insert (no direct move operation)

## 1️⃣ Data Structures

1. **Dictionary `cache`**

   * Stores `key → node`
   * Value is inside Node

2. **Doubly Linked List**

   * Node stores `(key, val)`
   * Order = usage order
   * `head`/`tail` are sentinels, not counted
   * Operations: move to tail, remove from head

3. **Capacity Check**

   * Use `len(cache) >= cap`

**Mnemonic:**

> Dictionary lookup fast, list keeps order, sentinels ignored, capacity via dict

## 4. Code Implementation:

```
class Node:
    def __init__(self, key=0, val=0):
        self.key = key
        self.val = val
        self.prev = None
        self.next = None

class LRUCache:

    def __init__(self, capacity: int):
        self.cap = capacity
        self.cache = {}  # key -> Node
        self.head = Node()
        self.tail = Node()
        self.head.next = self.tail
        self.tail.prev = self.head

    def _remove(self, node):
        prev, nxt = node.prev, node.next
        prev.next = nxt
        nxt.prev = prev

    def _add_to_tail(self, node):
        prev, nxt = self.tail.prev, self.tail
        prev.next = node
        node.prev = prev
        node.next = nxt
        nxt.prev = node

    def get(self, key: int) -> int:
        if key not in self.cache:
            return -1
        node = self.cache[key]
        self._remove(node)
        self._add_to_tail(node)  
        return node.val

    def put(self, key: int, value: int) -> None:
        if key in self.cache:
            node = self.cache[key]
            node.val = value
            self._remove(node)
            self._add_to_tail(node)
        else:
            if len(self.cache) >= self.cap:
                lru = self.head.next
                self._remove(lru)
                del self.cache[lru.key]
            node = Node(key, value)
            self.cache[key] = node
            self._add_to_tail(node)

# Your LRUCache object will be instantiated and called as such:
# obj = LRUCache(capacity)
# param_1 = obj.get(key)
# obj.put(key,value)   
```
