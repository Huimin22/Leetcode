## 1. Problem

146. LRU Cache
    
## 2. Summary

* O(1) get + O(1) put

* Use **HashMap + Doubly Linked List**

* HashMap: `key -> node`

* Doubly Linked List: maintain usage order

* `head.next` = LRU

* `tail.prev` = MRU

* Access node → remove + add_to_tail (mark MRU)

* Insert new node → add_to_tail

* If full → remove head.next + delete from map

* List size == Map size

* Every node in map must be in list

* Move = remove + insert (no direct move operation)


Node initialization:
key, value, prev, next.

LRU initialization:
dict + doubly linked list + capacity (capacity tracks dictionary size; the linked list has dummy nodes so we don’t use its length).

_add method:
Idea: insert the newest (MRU) node at the tail.
Code: find the tail node’s prev and next nodes, then create new connections:

* node.prev connects with pren (two-way link)
* node.next connects with nxt (two-way link)

_remove method:
Find the node’s prev and next nodes, then connect these two nodes together with a two-way link.

### Core Operations

**Remove node**

```
prev = node.prev
next = node.next
prev.next = next
next.prev = prev
```

**Add to tail (mark MRU)**

```
prev = tail.prev
prev.next = node
node.prev = prev
node.next = tail
tail.prev = node
```

## 4. Code Implementation:

```
class Node:
    def __init__(self, key=0, val=0):
        self.key = key
        self.val = val
        self.prev = None
        self.next = None

class LRUCache:

    def __init__(self, capacity: int):
        self.cap = capacity
        self.cache = {}  # key -> Node
        self.head = Node()
        self.tail = Node()
        self.head.next = self.tail
        self.tail.prev = self.head

    def _remove(self, node):
        prev, nxt = node.prev, node.next
        prev.next = nxt
        nxt.prev = prev

    def _add_to_tail(self, node):
        prev, nxt = self.tail.prev, self.tail
        prev.next = node
        node.prev = prev
        node.next = nxt
        nxt.prev = node

    def get(self, key: int) -> int:
        if key not in self.cache:
            return -1
        node = self.cache[key]
        self._remove(node)
        self._add_to_tail(node)  
        return node.val

    def put(self, key: int, value: int) -> None:
        if key in self.cache:
            node = self.cache[key]
            node.val = value
            self._remove(node)
            self._add_to_tail(node)
        else:
            if len(self.cache) >= self.cap:
                lru = self.head.next
                self._remove(lru)
                del self.cache[lru.key]
            node = Node(key, value)
            self.cache[key] = node
            self._add_to_tail(node)

# Your LRUCache object will be instantiated and called as such:
# obj = LRUCache(capacity)
# param_1 = obj.get(key)
# obj.put(key,value)   
```

## Data Structures Mental Template

**Data Structures**

* `cache = {}` → key → node, fast lookup
* `cap` → capacity limit
* Doubly linked list with `head`/`tail` sentinels → maintain usage order

**Node**

* `key`, `val`, `prev`, `next`

**Initialization**

```python
self.cache = {}
self.cap = capacity
self.head = Node()
self.tail = Node()
self.head.next = self.tail
self.tail.prev = self.head
```

**Core Operations**

* `_add(node)` → insert before tail (most recent)
* `_remove(node)` → detach from list
* `get(key)` → return value + move node to tail
* `put(key, val)` → update or add, remove LRU if over capacity

**Capacity Check**

* `len(self.cache) >= self.cap` → remove `head.next`

**Mnemonic**

> Dictionary fast, list keeps order, sentinels ignored, capacity via dict

**Second**
Cache is to store the key and node itself. Get the value from the node not by the cache dict.

The linkedlist stores the node.

* `self.head = None()` / `self.tail = None()` → invalid, should be `Node()`
* `self.cache()` → dictionary is not callable, use `self.cache`
* Head/tail must be actual nodes before setting `next`/`prev`
