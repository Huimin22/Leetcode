## 1. Problem
764. Largest Plus Sign
    
## 2. Summary
Mental Template — DP (Largest Plus Sign)
- Initialize grid with 1; set mines to 0.
- Calculate consecutive 1s in four directions: up, down, left, right.
- For each cell, order = min(up, down, left, right).
- Return the maximum order.


## 3. Key Points
Approach: Dynamic Programming (DP)

Key Idea: Count consecutive 1s in four directions: up, down, left, right.

Formula: order = min(up, down, left, right)

Result: Return the maximum order.



## 4. Code Implementation:


```
class Solution:
    def orderOfLargestPlusSign(self, n: int, mines: list[list[int]]) -> int:
        grid = [[1] * n for _ in range(n)]

        for r, c in mines:
            grid[r][c] = 0

        up = [[0] * n for _ in range(n)]
        down = [[0] * n for _ in range(n)]
        left = [[0] * n for _ in range(n)]
        right = [[0] * n for _ in range(n)]

        # Up and Left
        for i in range(n):
            for j in range(n):
                if grid[i][j] == 1:
                    up[i][j] = 1 + (up[i - 1][j] if i > 0 else 0)
                    left[i][j] = 1 + (left[i][j - 1] if j > 0 else 0)

        # Down and Right
        for i in range(n - 1, -1, -1):
            for j in range(n - 1, -1, -1):
                if grid[i][j] == 1:
                    down[i][j] = 1 + (down[i + 1][j] if i < n - 1 else 0)
                    right[i][j] = 1 + (right[i][j + 1] if j < n - 1 else 0)

        # Find the largest plus sign
        answer = 0

        for i in range(n):
            for j in range(n):
                order = min(
                    up[i][j],
                    down[i][j],
                    left[i][j],
                    right[i][j]
                )
                answer = max(answer, order)

        return answer   


```

    Time：\(O(n^2)\)
