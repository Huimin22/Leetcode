## 1. Problem

400. Nth Digit
    
## 2. Summary

1. **Digit segments**

   * k-digit numbers:

     * count = `9 * 10^(k-1)`
     * length = `count * k`

2. **Find segment**

   ```
   while n > k * count:
       n -= k * count
       k += 1
       count *= 10
       start *= 10
   ```

3. **Locate inside segment**

   ```
   n -= 1
   num = start + n // k
   digit = str(num)[n % k]
   ```

4. **Core idea**

   * Subtract whole digit blocks
   * Use // to find number
   * Use % to find digit inside number
   * Never build full sequence


## 3. Key Points

* Numbers grouped by digit length (1-digit, 2-digit, 3-digit…).
* Each group length = `digits * count`.
* Subtract whole groups until n falls in one group.
* Convert to 0-based: `n -= 1`.
* Number index = `n // digits`.
* Digit index = `n % digits`.
* Target number = `start + number_index`.
* Answer = digit at `digit_index`.
* Do not generate full sequence.
* Time O(log n), Space O(1).

## 4. Code Implementation:


```
class Solution:
    def findNthDigit(self, n: int) -> int:
        digits = 1
        count = 9
        start = 1

        while n > digits * count:
            n -=  digits * count
            digits += 1
            count *= 10
            start *= 10

        n -= 1
        num = start + n//digits
        digit_index = n%digits

        return int(str(num)[digit_index])   


```

## 5. Complexity Analysis

    Time: O(log n)
    
    Space: O(1)
