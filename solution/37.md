## 1. Problem

37. Sudoku Solver
    
## 2. Summary

```
for each empty cell:
    try each candidate:
        if valid:
            place number
            if dfs(): return True
            undo placement  # backtrack
    return False  # all candidates failed
return True  # all cells filled
```


```
for each cell:
    if cell == '.':
        for num in '1'..'9':
            if num not in row/col/box:
                place num
                update 3 sets

                if dfs(): return True

                undo placement
                revert 3 sets

        return False   # no valid num for this cell

return True   # all cells filled no empty cell → completed
```


## 3. Key Points

- DFS = try one path to the end, backtrack if fail
- each level = one empty cell
- choice = digits 1~9
- prune = check row/col/box sets
- place → recurse → undo
- if dfs() == True → solution found, stop
- if all digits fail → return False (backtrack)
- if no empty cell → return True

## 4. Code Implementation:


```
 class Solution:

    def solveSudoku(self, board):
        rows = [set() for _ in range(9)]
        cols = [set() for _ in range(9)]
        boxes = [set() for _ in range(9)]
        
        for i in range(9):
            for j in range(9):
                if board[i][j] != ".":
                    num = board[i][j]
                    rows[i].add(num)
                    cols[j].add(num)
                    boxes[(i//3)*3 + j//3].add(num)
        
        def dfs():
            for i in range(9):
                for j in range(9):
                    if board[i][j] == ".":
                        b = (i//3)*3 + j//3
                        for num in "123456789":
                            if num not in rows[i] and num not in cols[j] and num not in boxes[b]:
                                board[i][j] = num
                                rows[i].add(num)
                                cols[j].add(num)
                                boxes[b].add(num)
                                
                                if dfs():
                                    return True
                                
                                board[i][j] = "."
                                rows[i].remove(num)
                                cols[j].remove(num)
                                boxes[b].remove(num)
                        return False
            return True
        
        dfs()
          
```
