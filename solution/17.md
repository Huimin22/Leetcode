## 4. Code Implementation:


```
 class Solution:
    def letterCombinations(self, digits: str) -> List[str]:
        res = []
        dic = {
            '2': ['a','b','c'],
            '3': ['d','e','f'],
            '4': ['g','h','i'],
            '5': ['j','k','l'],
            '6': ['m','n','o'],
            '7': ['p','q','r','s'],
            '8': ['t','u','v'],
            '9': ['w','x','y','z']
            }
        if digits == "":
            return res
        def dfs(path, index):
            if index == len(digits):
                res.append("".join(path))
                return
            letter_key = digits[index]
            for e in dic[letter_key]:
                path.append(e)
                dfs(path, index+1)
                path.pop()
        dfs([], 0)
        return res  
```

## 8. Note

* Used list `path` in DFS but forgot to `return` in base case → caused recursion to continue past valid path.
* Base case must `return` after appending result to avoid index out-of-range or invalid extra recursion.
* Confused `index` vs `len(path)` as termination, but logic is equivalent; still need explicit `return`.
