## **Encode and Decode Strings (LeetCode 271)**

Design an algorithm to encode a list of strings to a single string. The encoded string is then sent over the network and can be decoded back to the original list of strings.

**Constraints:**

* The list of strings may contain any characters, including letters, digits, and special characters.
* Do not use any built-in serialization methods (like `eval` or `json`).

---

### **Example 1**

**Input:**

```python
["hello", "world"]
```

**Encoding (one possible output):**

```
"5#hello5#world"
```

**Decoding:**

```
["hello", "world"]
```

---

### **Example 2**

**Input:**

```python
["", "abc", "x#y"]
```

**Encoding:**

```
"0#3#abc3#x#y"
```

**Decoding:**

```
["", "abc", "x#y"]
```
