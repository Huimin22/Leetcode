## 1. Problem


### **Encode and Decode Strings (LeetCode 271)**

Design an algorithm to encode a list of strings to a single string. The encoded string is then sent over the network and can be decoded back to the original list of strings.

**Constraints:**

* The list of strings may contain any characters, including letters, digits, and special characters.
* Do not use any built-in serialization methods (like `eval` or `json`).

---

### **Example 1**

**Input:**

```python
["hello", "world"]
```

**Encoding (one possible output):**

```
"5#hello5#world"
```

**Decoding:**

```
["hello", "world"]
```

## 2. Summary

```python
class Solution:
    def encode(self, strs):
        return "".join(f"{len(s)}#{s}" for s in strs)

    def decode(self, s):
        res, i = [], 0
        while i < len(s):
            j = i
            while s[j] != "#": j += 1
            length = int(s[i:j])
            res.append(s[j+1:j+1+length])
            i = j + 1 + length
        return res
```

## 3. Key Points

* Use `length#string` for each string → safe for any character
* Two pointers: `i` for start of length, `j` to find `#`
* Slice `length` characters after `#` → append → move `i`

## 4. Code Implementation:

```
class Solution:
    def encode(self, strs):
        res = ""
        for s in strs:
            res += str(len(s)) + "#" + s
        return res

    def decode(self, s):
        res = []
        i = 0
        while i < len(s):
            j = i
            while s[j] != "#":
                j += 1
            s_len = int(s[i:j])
            cur_s = s[j+1:j+1+s_len]
            res.append(cur_s)
            i = j + 1 + s_len
        return res
```
