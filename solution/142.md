## 1. Problem

142. Linked List Cycle II
    
## 2. Summary

1. Use slow & fast pointers from head
2. Move: slow 1 step, fast 2 steps
3. while fast & fast.next:
       if slow == fast: break
       slow = slow.next
       fast = fast.next.next
   else: return None  # no cycle
4. Set slow2 = head
5. Move slow & slow2 1 step each until meet
6. Return meeting node (cycle start)

## 3. Key Points

- Use slow/fast pointers to detect cycle
- fast moves 2 steps, slow 1 step
- If fast or fast.next is None → no cycle
- If slow == fast → cycle exists
- From head, move slow2 and slow 1 step each
- First meeting node = cycle start
- while…else handles no-cycle edge cases


## 4. Code Implementation:

```
class Solution:
    def detectCycle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if not head:
            return None 

        slow = head
        fast = head
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
            if slow == fast:
                break
        else:
            return None
        
        slow2 = head
        while slow2 != slow:
            slow = slow.next
            slow2 = slow2.next
        return slow   
```

    Time：O(n)
        
    Space: O(1)
