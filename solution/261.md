## 1. Problem

261. Graph Valid Tree (Locked)

Given n nodes labeled from 0 to n-1 and a list of undirected edges (each edge is a pair of nodes), write a function to check whether these edges make up a valid tree.

Example 1:

Input: n = 5, and edges = [[0,1], [0,2], [0,3], [1,4]]
Output: true

Example 2:

Input: n = 5, and edges = [[0,1], [1,2], [2,3], [1,3], [1,4]]
Output: false

Note: you can assume that no duplicate edges will appear in edges. Since all edges are undirected, [0,1] is the same as [1,0] and thus will not appear together in edges.
  
## 2. Summary

1. Check tree by edges: tree has n nodes and n-1 edges.
2. Build graph using list or dict, initialize graph.
3. Use queue `q` and visited set `v`; push `(node, parent)` to `q`, node to `v`.
4. While `q` not empty, pop `cur_node`.
5. For each neighbor `nei` of `cur_node`, if `nei` not in `v`, add `(nei, cur_node)` to `q` and add `nei` to `v`.
6. Else if `nei != parent`, return False (found cycle).
7. After traversal, return True if all nodes visited (connected) and no cycle.

## 3. Key Points

tree:
    edges == n - 1
    connected

undirected graph:
    visited neighbor != cycle
    visited and != parent → cycle
    visited and == parent → ignore

BFS:
    queue stores (node, parent)
    parent avoids false cycle

this problem:
    edges == n - 1 → no cycle
    only need check connectivity

## 4. Code Implementation:

```
from collections import defaultdict, deque
from typing import List

class Solution:
    def validTree(self, n: int, edges: List[List[int]]) -> bool:
        if len(edges) != n - 1:
            return False
        
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)
        
        visited = set([0])
        queue = deque([(0, -1)])  # BFS: (node, parent)
        
        while queue:
            node, parent = queue.popleft()
            for nei in graph[node]:
                if nei not in visited:
                    visited.add(nei)
                    queue.append((nei, node))
                else:
                    if nei != parent:
                        return False
        
        return len(visited) == n   
```
