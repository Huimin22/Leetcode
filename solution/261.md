## 1. Problem

261. Graph Valid Tree
    
## 2. Summary

if len(edges) != n - 1: return False

build graph

BFS from any node (e.g. 0):
    use visited set
    push (node, parent)
    for each neighbor:
        if not visited:
            add to queue
        elif neighbor != parent:
            return False   # cycle

return len(visited) == n   # connected

## 3. Key Points

tree:
    edges == n - 1
    connected

undirected graph:
    visited neighbor != cycle
    visited and != parent → cycle
    visited and == parent → ignore

BFS:
    queue stores (node, parent)
    parent avoids false cycle

this problem:
    edges == n - 1 → no cycle
    only need check connectivity

## 4. Code Implementation:

```
from collections import defaultdict, deque
from typing import List

class Solution:
    def validTree(self, n: int, edges: List[List[int]]) -> bool:
        if len(edges) != n - 1:
            return False
        
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)
        
        visited = set([0])
        queue = deque([(0, -1)])  # BFS: (node, parent)
        
        while queue:
            node, parent = queue.popleft()
            for nei in graph[node]:
                if nei not in visited:
                    visited.add(nei)
                    queue.append((nei, node))
                else:
                    if nei != parent:
                        return False
        
        return len(visited) == n   
```
