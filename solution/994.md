## 1. Problem

994. Rotting Oranges
    
## 2. Summary

1. Initialize queue with all rotten oranges, count fresh oranges.
2. minutes = 0
3. while queue not empty and fresh > 0:
       for each orange in current level:
           for each 4-direction neighbor:
               if neighbor is fresh:
                   mark rotten
                   fresh -= 1
                   add to queue
       minutes += 1
4. return minutes if fresh == 0 else -1

## 3. Key Points

* Multi-source BFS from all rotten oranges.
* Track fresh count.
* Each BFS level = 1 minute.
* Spread to adjacent fresh oranges, decrease fresh count.
* Stop when queue empty or no fresh left.
* Return minutes if all rotten, else -1.

## 4. Code Implementation:

```
class Solution:
    def orangesRotting(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        queue = deque()
        fresh_count = 0

        for i in range(m):
            for j in range(n):
                if grid[i][j] == 2:
                    queue.append((i, j))
                elif grid[i][j] == 1:
                    fresh_count += 1

        minutes = 0
        directions = [(0,1), (1,0), (0,-1), (-1,0)]

        while queue and fresh_count > 0:
            for _ in range(len(queue)):
                x, y = queue.popleft()
                for dx, dy in directions:
                    nx, ny = x + dx, y + dy
                    if 0 <= nx < m and 0 <= ny < n and grid[nx][ny] == 1:
                        grid[nx][ny] = 2
                        fresh_count -= 1
                        queue.append((nx, ny))
            minutes += 1

        return minutes if fresh_count == 0 else -1   
```
