## 1. Problem

103. Binary Tree Zigzag Level Order Traversal
    
## 2. Summary

```
BFS level order
queue = deque([root])
flag = True  # left->right

while queue:
    level = deque()
    for _ in range(len(queue)):
        node = queue.popleft()
        if flag:
            level.append(node.val)
        else:
            level.appendleft(node.val)
        if node.left: queue.append(node.left)
        if node.right: queue.append(node.right)
    res.append(list(level))
    flag = not flag
```

## 3. Key Points

BFS unchanged, only level insertion direction changes using deque and flag.

## 4. Code Implementation:

```
class Solution:
    def zigzagLevelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        if not root:
            return []
        q = deque([root])
        flag = True
        res = []
        while q: 
            n = len(q)
            level = deque()

            for _ in range(n):
                cur_n = q.popleft()
                if flag:
                    level.append(cur_n.val)
                else:
                    level.appendleft(cur_n.val)

                if cur_n.left:
                    q.append(cur_n.left)
                if cur_n.right:
                    q.append(cur_n.right)
            res.append(list(level))
            flag = not flag
        return res   
```

3. Forgot to flip `flag` after each level.
