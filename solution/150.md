## 1. Problem

150. Evaluate Reverse Polish Notation
    
## 2. Summary

Scan tokens left → right.
Number → push to stack.
Operator → pop b, pop a → compute `a op b` → push result.
Division → truncate toward zero.
Final result = stack top.

## 3. Key Points

Use stack.
Number → push.
Operator → pop b, pop a → `a op b` → push result.
Order matters for `-` and `/`.
Division truncates toward zero.
Final answer = stack top.

## 4. Code Implementation:

```
class Solution:
    def evalRPN(self, tokens: List[str]) -> int:
        stack = []
        for t in tokens:
            if t in  '+-*/':
                b = stack.pop()
                a = stack.pop()
                if t == '+':
                    stack.append(a+b)
                elif t == '-':
                    stack.append(a-b)
                elif t == '*':
                    stack.append(a*b)
                else:
                    stack.append(int(a/b))
            else:
                stack.append(int(t))
        return stack[0]  
```
