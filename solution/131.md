## 1. Problem

131. Palindrome Partitioning
    
## 2. Summary


```python
res = []

def is_palindrome(s):
    return s == s[::-1]

def dfs(start, path):
    if start == len(s):
        res.append(path[:])
        return
    for end in range(start+1, len(s)+1):
        seg = s[start:end]
        if is_palindrome(seg):
            path.append(seg)
            dfs(end, path)
            path.pop()

dfs(0, [])
return res
```

## 3. Key Points

* DFS parameter is `start` index, next DFS starts from `end`.
* `for end in range(start+1, len(s)+1)` → generate substring `s[start:end]`.
* Check if substring is palindrome → only then append to path.
* Path stores valid palindromic segments.
* Backtrack with `path.pop()` after recursion.
* Index controls recursion; substring is what’s checked.

## 4. Code Implementation:

```
class Solution:
    def partition(self, s: str) -> List[List[str]]:
        res = []
        
        def is_palindrome(sub) :
            return sub == sub[::-1]

            if start == len(s):

            for end in range(start + 1, len(s) + 1):
                seg = s[start:end]
                if is_palindrome(seg):
                    path.append(seg)
                    dfs(end, path)
                    path.pop()
        
        dfs(0, [])
        return res     

```

## 8. Note

**Second**

* Used `index` instead of `start`, causing inconsistent recursion.
* Called `dfs(index+1, path)`, skipping longer substrings. Next index in dfs should be end.
* `for end in range(index+1, len(s)+1)` misses valid partitions.
* Should iterate `end` from `start+1` to `len(s)+1` and recurse with `dfs(end, path)`.
*  for end in range(start+1, len(s)+1) not includ len(s)+1

** Third**

start fixed, end goes from start + 1 up to len(s)

**“Substring starts at start, length at least 1, goes up to the string’s end (exclusive).”** 

**Fourth**


1. **Broken Palindrome Logic:** `x[::-1]` returns a string; it must be `x == x[::-1]` to return a boolean.
2. **Incorrect Loop Range:** `(start+1, len(s))` iterates a tuple of two values; it must be `range(start + 1, len(s) + 1)` to check every possible cut.
3. **Missing Initialization:** The `res` list was not defined, and the initial `dfs(0, [])` call was missing.
