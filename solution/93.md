## 1. Problem

93. Restore IP Addresses
    
## 2. Summary

* DFS, path stores selected segments (list of strings)
* Choice = length 1~3 for next segment
* Slice: `s[start:start+length]`, ensure `start+length <= len(s)`
* Check segment valid: 0~255, no leading zero (except "0")
* If valid, dfs(start+length, path+[segment])
* Collect if len(path)==4 and start==len(s)
* Backtrack automatically with path + [segment]

## 3. Key Points

Slice takes indices `start` to `start+l-1`; right boundary `end` can equal `start+l`. 

* DFS with path as list of segments
* Choice: length 1–3 for next segment
* Slice: s[start:start+length], start+length ≤ len(s)
* Segment valid: 0–255, no leading zero except "0"
* Recurse: dfs(start+length, path+[segment])
* Collect when len(path)=4 and start=len(s)
* Backtrack automatically via path+[segment]

## 4. Code Implementation:

```
class Solution:
    def restoreIpAddresses(self, s: str) -> List[str]:
        res = []

        def is_valid(segment):
            if not segment:
                return False
            if len(segment) > 1 and segment[0] == '0':
                return False
            return 0 <= int(segment) <= 255

        def dfs(start, path):
            if len(path) == 4:
                if start == len(s):
                    res.append('.'.join(path))
                return

            for length in range(1, 4):
                if start + length <= len(s):
                    segment = s[start:start+length]
                    if is_valid(segment):
                        dfs(start + length, path + [segment])

        dfs(0, [])
        return res   

```
