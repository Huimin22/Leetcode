## 1. Problem

300. Longest Increasing Subsequence
    
## 2. Summary

DP

dp = [1]*len(nums)
for i in range(len(nums)):
    for j in range(i):
        if nums[j] < nums[i]:
            dp[i] = max(dp[i], dp[j]+1)
return max(dp)

## 3. Key Points

* `dp[i]` = LIS ending at i
* Only append if `nums[j] < nums[i]` → strictly increasing
* LIS ≠ continuous → can skip elements
* `max(dp)` = length of overall LIS

### **State Definition**

```text
dp[i] = length of the longest increasing subsequence ending with nums[i]
```

---

### **State Transition**

* Enumerate all `j < i`
* Only consider `nums[j] < nums[i]`
* Update length:

```python
dp[i] = max(dp[i], dp[j] + 1)
```

* Meaning: append `nums[i]` after `nums[j]` and take the sequence with the maximum length

---

### **Initialization**

```python
dp[i] = 1  # minimum length is nums[i] itself
```

---

### **Result**

* LIS may **not** end at the last element
* Return the maximum value in the dp array:

```python
return max(dp)
```

---

### **Key Points**

* `dp[i]` ≠ nums[i]; it represents **length**
* Inner loop finds all valid `j` and appends `nums[i]` to form the longest sequence
* Do **not** return `dp[n-1]`; always use `max(dp)`

---

### **One-line Mental Template**

```text
dp[i] = max(dp[j] + 1 for j < i if nums[j] < nums[i]); final answer = max(dp)
```

## 4. Code Implementation:

```
class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        n = len(nums)
        dp = [1]*(n)
        for i in range(n):
            for j in range(i):
                if nums[j] < nums[i]:
                    dp[i] = max(dp[i], dp[j] + 1)
        return max(dp)

```
