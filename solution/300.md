## 1. Problem

300. Longest Increasing Subsequence
    
## 2. Summary

DP

dp = [1]*len(nums)
for i in range(len(nums)):
    for j in range(i):
        if nums[j] < nums[i]:
            dp[i] = max(dp[i], dp[j]+1)
return max(dp)

## 3. Key Points

* `dp[i]` = LIS ending at i
* Only append if `nums[j] < nums[i]` → strictly increasing
* LIS ≠ continuous → can skip elements
* `max(dp)` = length of overall LIS

## 4. Code Implementation:

```
class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        n = len(nums)
        dp = [1]*(n)
        for i in range(n):
            for j in range(i):
                if nums[j] < nums[i]:
                    dp[i] = max(dp[i], dp[j] + 1)
        return max(dp)

```

## 8. Note

**Mistake**

* Thought LIS needed consecutive elements → it doesn’t, subsequence can skip.
* Confused `nums[j] < nums[i]` with continuity → it only ensures strictly increasing.
* Didn’t realize LIS can end at any index → must use `max(dp)`, not `dp[-1]`.
* Misunderstood how `dp[i]` builds → it extends **any valid previous subsequence**, not just the immediate previous element.
