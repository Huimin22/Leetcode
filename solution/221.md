"The left and top ensure the edges, while the top-left ensures the interior; the smallest of the three limits the maximum square size you can form."

## 3. Key Points

* Left + top → edges
* Top-left → interior
* min of three → max square side

## 4. Code Implementation:


```
class Solution:
    def maximalSquare(self, matrix: List[List[str]]) -> int:       
        if not matrix:
            return 0
        m, n = len(matrix), len(matrix[0])
        dp = [[0]*n for _ in range(m)]
        max_side = 0

        for i in range(m):
            for j in range(n):
                if matrix[i][j] == '1':
                    if i == 0 or j == 0:
                        dp[i][j] = 1
                    else:
                        dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1
                    max_side = max(max_side, dp[i][j])
        return max_side * max_side   

```
