## 1. Problem

228. Summary Ranges
    
## 2. Summary

```text
start = first element
for num in nums[1:]:
    if num != prev + 1:
        add start->prev (or start if start==prev)
        start = num
add start->last (or start if start==last)
```

## 3. Key Points

```text
- Track start of current range
- If current != prev + 1: close previous range (start==prev → single)
- Update start = current
- After loop: close last range
```

## 4. Code Implementation:


```
class Solution:
    def summaryRanges(self, nums: List[int]) -> List[str]:
        if not nums:
            return []
        res = []
        start = nums[0]
        for i in range(1, len(nums)):
            if nums[i] != nums[i-1] + 1:
                if start == nums[i-1]:
                    res.append(str(start))
                else:
                    res.append(f"{start}->{nums[i-1]}")
                start = nums[i]
        if start == nums[-1]:
            res.append(str(start))
        else:
            res.append(f"{start}->{nums[-1]}")
        return res
   
```
