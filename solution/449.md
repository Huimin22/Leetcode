## 1. Problem

449. Serialize and Deserialize BST
    
## 2. Summary

serialize:
preorder traversal (root → left → right)
store values as string (comma-separated)

deserialize:
read preorder list
use BST property + range (min, max)
build tree recursively:
  if val not in range → stop
  root = val
  left = (min, val)
  right = (val, max)

## 3. Key Points
