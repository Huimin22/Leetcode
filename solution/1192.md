## 1. Problem

1192. Critical Connections in a Network
    
## 2. Summary

## Template

* Initialize `disc[u] = low[u] = time`; increment `time`.
* For each neighbor `v` of `u`:

  * If `v == parent`, skip (avoid counting the edge back).
  * If `v` is unvisited (`disc[v] == -1`):

    * DFS(v, u). After DFS completes, all `disc` and `low` values in v’s subtree are updated.
    * Update `low[u] = min(low[u], low[v])` using subtree info.
    * If `low[v] > disc[u]`, `(u,v)` is a bridge (v’s subtree cannot reach earlier nodes without this edge).
  * Else (`v` visited):

    * It is a back edge (excluding parent).
    * Update `low[u] = min(low[u], disc[v])` using only `disc[v]` (ancestor info); do not use `low[v]` because it contains subtree info and would confuse u’s low value.  




## Bridge Checking Logic

```python
if low[v] > disc[u]:
    (u, v) is a bridge
```

### Breakdown:

**`low[v]`**

* The earliest reachable node in the subtree rooted at `v`
* Stable after `dfs(v, u)` completes

**`disc[u]`**

* The visit timestamp of node `u`
* `u` is the parent of `v` in the DFS tree

---

### Why `>` means a bridge

```text
low[v] > disc[u] → the earliest node v’s subtree can reach is later than u
                   → the subtree cannot reach u or any ancestor of u
                   → the only path connecting v’s subtree to the rest of the graph is (u, v)
                   → therefore, (u, v) is a bridge
```

---

### Why `<=` is not a bridge

```text
low[v] <= disc[u] → the subtree has a path that loops back to u or an ancestor
                    → deleting (u, v) will not disconnect the graph
                    → therefore, (u, v) is not a bridge
```

---

### 🔹 One-line intuition

Compare the neighbor `v`’s low value with your own visit time `disc[u]`:

* `low[v] > disc[u]` → the edge is the only connection → **bridge**
* `low[v] <= disc[u]` → the subtree can loop back → **not a bridge**

else:
                    low[u] = min(low[u], disc[v])

**Back edge → use `disc[v]` only, to record the earliest ancestor that `u` can reach; tree edge → use `low[v]`, which includes all the lowest reachable points in the subtree.**

* idea:

  * low = “how early subtree can go back”
  * bridge = “subtree cannot bypass u”


Update low:

“Can I reach an earlier node through my subtree?”

Check bridge:

“Can the subtree bypass me (reach me or my ancestors without this edge)?”



* `disc[u]` = timestamp when `u` is first visited.
* `low[u]` = earliest timestamp reachable from `u` (including its subtree).
* `parent` = the node from which `u` was visited; skip `v == parent` to avoid counting the edge back.
* DFS visit:

  * **Unvisited neighbor `v` (`disc[v] == -1`)** → DFS(v,u), update `low[u] = min(low[u], low[v])`.

    * If `low[v] > disc[u]` → edge `(u,v)` is a bridge (v’s subtree cannot reach u or earlier).
  * **Visited neighbor `v` (back edge)** → update `low[u] = min(low[u], disc[v])` (only care about earliest ancestor reachable).
* Bridge condition: `low[v] > disc[u]` → subtree cannot bypass u → edge is bridge; else → not bridge.
* DFS timestamps increment strictly per visit; low values are updated dynamically via DFS and back edges.
* Key intuition:

  * Tree edge → use `low[v]` (subtree info).
  * Back edge → use `disc[v]` (ancestor info only).

## 4. Code Implementation:

```
from typing import List
from collections import defaultdict

class Solution:
    def criticalConnections(self, n: int, connections: List[List[int]]) -> List[List[int]]:
        graph = defaultdict(list)
        for u, v in connections:
            graph[u].append(v)
            graph[v].append(u)

        disc = [-1] * n
        low = [-1] * n
        time = 0
        res = []

        def dfs(u, parent):
            nonlocal time
            disc[u] = low[u] = time
            time += 1
            for v in graph[u]:
                if v == parent:
                    continue
                if disc[v] == -1:
                    dfs(v, u)
                    low[u] = min(low[u], low[v])
                    if low[v] > disc[u]:
                        res.append([u, v])
                else:
                    low[u] = min(low[u], disc[v])

        dfs(0, -1)
        return res    

```
