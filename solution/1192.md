## 1. Problem

1192. Critical Connections in a Network
    
## 2. Summary

* build graph
* disc[u] = visit time (fixed)
* low[u] = earliest reachable time (dynamic)

DFS(u, parent):

* disc[u] = low[u] = time++
* for v in neighbors:

  * if v == parent: continue
  * if not visited:

    * dfs(v, u)
    * low[u] = min(low[u], low[v])
    * if low[v] > disc[u]: (u,v) is bridge
  * else:

    * low[u] = min(low[u], disc[v])




## Bridge Checking Logic

```python
if low[v] > disc[u]:
    (u, v) is a bridge
```

### Breakdown:

**`low[v]`**

* The earliest reachable node in the subtree rooted at `v`
* Stable after `dfs(v, u)` completes

**`disc[u]`**

* The visit timestamp of node `u`
* `u` is the parent of `v` in the DFS tree

---

### Why `>` means a bridge

```text
low[v] > disc[u] → the earliest node v’s subtree can reach is later than u
                   → the subtree cannot reach u or any ancestor of u
                   → the only path connecting v’s subtree to the rest of the graph is (u, v)
                   → therefore, (u, v) is a bridge
```

---

### Why `<=` is not a bridge

```text
low[v] <= disc[u] → the subtree has a path that loops back to u or an ancestor
                    → deleting (u, v) will not disconnect the graph
                    → therefore, (u, v) is not a bridge
```

---

### 🔹 One-line intuition

Compare the neighbor `v`’s low value with your own visit time `disc[u]`:

* `low[v] > disc[u]` → the edge is the only connection → **bridge**
* `low[v] <= disc[u]` → the subtree can loop back → **not a bridge**

## 3. Key Points


* disc[u]: visit time, fixed

* low[u]: earliest reachable time, dynamic

* init: disc[u] = low[u] = time++

* tree edge (unvisited v):

  * dfs(v)
  * low[u] = min(low[u], low[v])

* back edge (visited v, not parent):

  * low[u] = min(low[u], disc[v])

* bridge:

  * if low[v] > disc[u]

* idea:

  * low = “how early subtree can go back”
  * bridge = “subtree cannot bypass u”


Update low:

“Can I reach an earlier node through my subtree?”

Check bridge:

“Can the subtree bypass me (reach me or my ancestors without this edge)?”


## 4. Code Implementation:

```
from typing import List
from collections import defaultdict

class Solution:
    def criticalConnections(self, n: int, connections: List[List[int]]) -> List[List[int]]:
        graph = defaultdict(list)
        for u, v in connections:
            graph[u].append(v)
            graph[v].append(u)

        disc = [-1] * n
        low = [-1] * n
        time = 0
        res = []

        def dfs(u, parent):
            nonlocal time
            disc[u] = low[u] = time
            time += 1
            for v in graph[u]:
                if v == parent:
                    continue
                if disc[v] == -1:
                    dfs(v, u)
                    low[u] = min(low[u], low[v])
                    if low[v] > disc[u]:
                        res.append([u, v])
                else:
                    low[u] = min(low[u], disc[v])

        dfs(0, -1)
        return res    

```
