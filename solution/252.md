## 1. Problem

meeting room

## 2. Summary

greedy and sorting

## 3. Key Points

sort the interval, check if the current meeting's start time is less than the previous meeting's end time
        
## 4. Code Implementation:


```
class Solution:
    def canAttendMeetings(self, intervals: List[List[int]]) -> bool:   
        intevals.sort()
        for i in range(1, len(intervals)):
            if intevals[i][0] < intevals[i-1][1]:
                return False
        return True   

```

## 5. Complexity Analysis
    Time：O(nlogn)
        
    Space: O(1)
