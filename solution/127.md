## 1. Problem

127. Word Ladder
    
## 2. Summary

BFS.

Finding neighbors = For each letter, try replacing it with 'a' to 'z' → generate a new word → check if it exists in the word list → if it does, enqueue it.

```python
from collections import deque

def ladderLength(beginWord, endWord, wordList):
    wordSet = set(wordList)
    if endWord not in wordSet:
        return 0
    
    queue = deque([(beginWord, 1)])
    
    while queue:
        word, steps = queue.popleft()
        if word == endWord:
            return steps
        
        for i in range(len(word)):
            for c in 'abcdefghijklmnopqrstuvwxyz':
                next_word = word[:i] + c + word[i+1:]
                if next_word in wordSet:
                    wordSet.remove(next_word)
                    queue.append((next_word, steps + 1))
    
    return 0
```

## 3. Key Points

* BFS → shortest path
* Queue = `(word, steps)`
* One letter change each position
* Only use words in `wordSet`
* Remove visited word from `wordSet`
* Return `steps` if reach `endWord`, else 0

```
from collections import deque

class Solution:
    def ladderLength(self, beginWord: str, endWord: str, wordList: list[str]) -> int:
        wordSet = set(wordList)
        if endWord not in wordSet:
            return 0

        queue = deque([(beginWord, 1)])  
        
        while queue:
            word, steps = queue.popleft()
            if word == endWord:
                return steps

            for i in range(len(word)):
                for c in 'abcdefghijklmnopqrstuvwxyz':
                    newWord = word[:i] + c + word[i+1:]
                    if newWord in wordSet:
                        queue.append((newWord, steps + 1))
                        wordSet.remove(newWord) 

        return 0   

```
