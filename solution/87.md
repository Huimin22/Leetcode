## 1. Problem

87. Scramble String
    
## 2. Summary

state: dfs(i1, i2, len) → s1[i1:i1+len] vs s2[i2:i2+len]

base:
- if substr equal → True
- if sorted chars not equal → False

try split:
for k in 1..len-1:
    case1 (no swap):
        dfs(i1, i2, k) and dfs(i1+k, i2+k, len-k)
    case2 (swap):
        dfs(i1, i2+len-k, k) and dfs(i1+k, i2, len-k)
    if any True → True

return False

memo: cache (i1, i2, len)

## 3. Key Points

- dfs + memo
- state: (i1, i2, len)
- prune: char count mismatch → False
- base: equal substring → True
- split k:
    no swap OR swap
- any True → True

## 4. Code Implementation:

```
from functools import lru_cache

class Solution:
    def isScramble(self, s1: str, s2: str) -> bool:
        
        @lru_cache(None)
        def dfs(i, j, length):
            if s1[i:i+length] == s2[j:j+length]:
                return True

            if sorted(s1[i:i+length]) != sorted(s2[j:j+length]):
                return False

            for k in range(1, length):
                if dfs(i, j, k) and dfs(i+k, j+k, length-k):
                    return True

                if dfs(i, j+length-k, k) and dfs(i+k, j, length-k):
                    return True

            return False

        return dfs(0, 0, len(s1))   
```
