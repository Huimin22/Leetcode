## 1. Problem

1143. Longest Common Subsequence
    
## 2. Summary

```text
dp[i][j] = LCS length of text1[0..i-1], text2[0..j-1]
dp[0][*] = dp[*][0] = 0

for i in 1..m:
    for j in 1..n:
        if text1[i-1] == text2[j-1]:
            dp[i][j] = dp[i-1][j-1] + 1
        else:
            dp[i][j] = max(dp[i-1][j], dp[i][j-1])

answer = dp[m][n]
```

## 3. Key Points

* Use **m+1 × n+1 DP array** for empty-string base case.
* **i/j start from 1**; access string as `text1[i-1]`, `text2[j-1]`.
* `if equal → dp[i-1][j-1]+1`, `else → max(up, left)`.
* Right-bottom `dp[m][n]` is the answer.

## 4. Code Implementation:


```
 class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        m, n = len(text1), len(text2)
        dp = [[0]*(n+1) for _ in range(m+1)]

        for i in range(1, m+1): 
            for j in range(1, n+1): 
                if text1[i-1] == text2[j-1]:
                    dp[i][j] = dp[i-1][j-1]+1
                else:
                    dp[i][j] = max(dp[i-1][j], dp[i][j-1])
        return dp[m][n]
  
```

**Mistakes**

* loop started from 0 → text[i-1]/text[j-1] caused index issues
* dp size same as string length → didn’t handle empty-string base case
