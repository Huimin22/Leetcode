```python
        def dfs():
            if vals[self.i] == '#':
```

## 3. Key Points

* Preorder DFS
* `#` marks null
* `self.i` tracks position
* Recursively builds left/right subtrees

```
# Definition for a binary tree node.
# class TreeNode(object):
#     def __init__(self, x):
#         self.val = x
#         self.left = None
#         self.right = None

class Codec:

    def serialize(self, root):
        """Encodes a tree to a single string.
        
        :type root: TreeNode
        :rtype: str
        """
        res = []
        def dfs(node):
            if not node:
                res.append("#")
                return
            res.append(str(node.val))
            dfs(node.left)
            dfs(node.right)
        dfs(root)
        return ",".join(res) 

    def deserialize(self, data):
        """Decodes your encoded data to tree.
        
        :type data: str
        :rtype: TreeNode
        """
        vals = data.split(",")
        self.index = 0

        def dfs():
            if vals[self.index] == "#":
                self.index += 1
                return None
            node = TreeNode(int(vals[self.index]))
            self.index += 1
            node.left = dfs()
            node.right = dfs()     
            return node
        
        return dfs()

```

**Sixth**

* Mutable objects** → Modifying their content inside an inner function works directly.
* Immutable objects** → Assigning a new value inside an inner function creates a local variable; you need `nonlocal` or `self` to modify the outer variable.
* When a node is `None`, you must `return`; otherwise, DFS will continue executing and accessing `node.val` will cause an error.
