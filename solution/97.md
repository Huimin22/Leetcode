## 1. Problem

97. Interleaving String
    
## 2. Summary

```python
# dp[i][j] = True if s3[:i+j] is interleaving of s1[:i] and s2[:j]
dp = [[False]*(n+1) for _ in range(m+1)]
dp[0][0] = True

for i in range(m+1):
    for j in range(n+1):
        if i > 0:
            dp[i][j] |= dp[i-1][j] and s1[i-1] == s3[i+j-1]
        if j > 0:
            dp[i][j] |= dp[i][j-1] and s2[j-1] == s3[i+j-1]

return dp[m][n]
```

## 3. Key Points

* Think **last char comes from s1 or s2**.
* Base case: empty s1 & s2 → empty s3.
* Iterate all prefixes of s1/s2.
* dp[i][j] depends on dp[i-1][j] or dp[i][j-1].

## 4. Code Implementation:


```
class Solution:
    def isInterleave(self, s1: str, s2: str, s3: str) -> bool:
        m, n = len(s1), len(s2)
        if m + n != len(s3):
            return False
        
        dp = [[False]*(n+1) for _ in range(m+1)]
        dp[0][0] = True 
        
        # first column, only using s1
        for i in range(1, m+1):
            dp[i][0] = dp[i-1][0] and s1[i-1] == s3[i-1]
        
        # first row, only using s2
        for j in range(1, n+1):
            dp[0][j] = dp[0][j-1] and s2[j-1] == s3[j-1]
        
        for i in range(1, m+1):
            for j in range(1, n+1):
                dp[i][j] = False  
                
                if dp[i-1][j] and s1[i-1] == s3[i+j-1]:
                    dp[i][j] = True
                
                if dp[i][j-1] and s2[j-1] == s3[i+j-1]:
                    dp[i][j] = True
        return dp[m][n]   


```
