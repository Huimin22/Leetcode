## 1. Problem

763. Partition Labels
    
## 2. Summary

* Precompute last occurrence of each char.
* Iterate string, maintain:

  * `end = farthest last index of chars seen so far`
  * `start = current partition start`
* For each index `i`:

  * update `end = max(end, last[s[i]])`
  * if `i == end`:

    * cut partition
    * record length `end - start + 1`
    * set `start = i + 1`
* Greedy merge by last positions.

## 3. Key Points




## 4. Code Implementation:


```
from typing import List

class Solution:
    def partitionLabels(self, s: str) -> List[int]:
        last = {c: i for i, c in enumerate(s)}
        res = []
        start = end = 0

        for i, c in enumerate(s):
            end = max(end, last[c])
            if i == end:
                res.append(end - start + 1)
                start = i + 1

        return res   

```
