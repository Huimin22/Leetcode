## 1. Problem

256 Paint House

There are a row of  n  houses, each house can be painted with one of the three colors: red, blue or green. The cost of painting each house with a certain color is different. You have to paint all the houses such that no two adjacent houses have the same color.

The cost of painting each house with a certain color is represented by a  _n_  x  _3_ cost matrix. For example, costs[0][0] is the cost of painting house 0 with color red; costs[1][2] is the cost of painting house 1 with color green, and so on... Find the minimum cost to paint all houses.

Note:
All costs are positive integers.

Example:

```
Input: [[17,2,17],[16,16,5],[14,3,19]]
Output: 10
Explanation: Paint house 0 into blue, paint house 1 into green, paint house 2 into blue. 
             Minimum cost: 2 + 5 + 3 = 10.

```
  
## 2. Summary

DP

dp[i][c] = cost[i][c] + min(dp[i-1][other two colors])
answer = min(last row)

State
dp[i][c] = min cost to paint [0..i] with house i color c

Init
dp[0][0] = costs[0][0]
dp[0][1] = costs[0][1]
dp[0][2] = costs[0][2]

```
Transition
dp[i][0] = costs[i][0] + min(dp[i-1][1], dp[i-1][2])
dp[i][1] = costs[i][1] + min(dp[i-1][0], dp[i-1][2])
dp[i][2] = costs[i][2] + min(dp[i-1][0], dp[i-1][1])
```

Order
i: 1 → n-1

Result
min(dp[n-1][0], dp[n-1][1], dp[n-1][2])

Optimize (O(1) space)
prev0, prev1, prev2
cur0 = cost[i][0] + min(prev1, prev2)
cur1 = cost[i][1] + min(prev0, prev2)
cur2 = cost[i][2] + min(prev0, prev1)
update prev = cur

## 3. Key Points

3 colors constraint → no same adjacent

only depend on previous row

choose min of other 2 colors

rolling update (O(1) space)

result = global min at last house

## 4. Code Implementation:


```

class Solution:
    def minCost(self, costs):
        if not costs:
            return 0

        prev = costs[0]

        for i in range(1, len(costs)):
            cur = [0] * 3
            cur[0] = costs[i][0] + min(prev[1], prev[2])
            cur[1] = costs[i][1] + min(prev[0], prev[2])
            cur[2] = costs[i][2] + min(prev[0], prev[1])
            prev = cur

        return min(prev)

```
