## 1. Problem

639. Decode Ways II
     
## 2. Summary

DP: Decode Ways II (639)

STATE
dp[i] = ways to decode s[0:i]

BASE
dp[0] = 1
dp[1] = single(s[0])

TRANSITION
dp[i] =
dp[i-1] * single(s[i-1])

* dp[i-2] * pair(s[i-2], s[i-1])

---

SINGLE(c)
c == '*' → 9
c == '0' → 0
else → 1

---

PAIR(a,b)

"**" → 15

"*b":
b <= '6' → 2
b >= '7' → 1

"a*":
a == '1' → 9
a == '2' → 6
else → 0

"ab":
10 <= int(ab) <= 26 → 1
else → 0

---

ROLLING DP

dp0 = dp[i-2]
dp1 = dp[i-1]

dp2 = (dp1 * single(s[i-1]) + dp0 * pair(s[i-2], s[i-1])) % MOD

shift:
dp0, dp1 = dp1, dp2

---

MOD
1e9 + 7


## 3. Key Points

BASE
dp[0] = 1
dp[1] = single(s[0])

TRANSITION

* **`dp2` ($dp[i]$):** The total number of ways to decode the string using the first $i$ characters.
* **`dp1` ($dp[i-1]$):** The total number of ways to decode the string using the first $i-1$ characters.
* **`dp0` ($dp[i-2]$):** The total number of ways to decode the string using the first $i-2$ characters.

dp[i] =
dp[i-1] * single(s[i-1])

* dp[i-2] * pair(s[i-2], s[i-1])

## 4. Code Implementation:

```
class Solution:
    def numDecodings(self, s: str) -> int:
        MOD = 10**9 + 7
        n = len(s)

        def single(c):
            if c == '*':
                return 9
            if c == '0':
                return 0
            return 1

        def pair(a, b):
            if a == '*' and b == '*':
                return 15
            if a == '*':
                if b <= '6':
                    return 2
                return 1
            if b == '*':
                if a == '1':
                    return 9
                if a == '2':
                    return 6
                return 0
            return 1 if 10 <= int(a + b) <= 26 else 0

        dp0, dp1 = 1, single(s[0])

        for i in range(2, n + 1):
            dp2 = (dp1 * single(s[i - 1]) + dp0 * pair(s[i - 2], s[i - 1])) % MOD
            dp0, dp1 = dp1, dp2

        return dp1       
```

## 8. Note

why return dp1:

### Corner Case Summary: $n=1$

* **Logic:** For a string of length 1, the `for i in range(2, n + 1)` loop becomes `range(2, 2)`, which is empty and **never executes**.
* **Variable Initialization:** `dp1` is initialized outside the loop as `single(s[0])`, but `dp2` is only defined inside the loop.
* **Return Value:** * `return dp1`: Returns the correctly initialized value for $n=1$.
    * `return dp2`: Triggers `UnboundLocalError` because the variable was never created.
* **Conclusion:** Returning `dp1` ensures the code is robust for both the base case ($n=1$) and the general case ($n \ge 2$).
