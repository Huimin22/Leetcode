## 2. Summary

```text
Union-Find (Connected Components)

init:
    parent[i] = i
    rank[i] = 0
    res = n

find(x):
    if parent[x] != x:
        parent[x] = find(parent[x])
    return parent[x]

union(x, y):
    px, py = find(x), find(y)
    if px == py:
        return 0
    attach smaller rank under larger
    if equal → increase rank
    return 1

for u, v in edges:
    res -= union(u, v)

return res
```

## 3. Key Points

```text
each node starts as its own component (res = n)

find: get root + path compression

union:
    if same root → no change
    else merge → components -= 1

use rank to keep tree shallow

res -= union(u, v)

final res = number of connected components
```

## 4. Code Implementation:


```
class Solution:
    def countComponents(self, n: int, edges):
        parent = list(range(n))
        rank = [0] * n

        def find(x):
            if parent[x] != x:
                parent[x] = find(parent[x])  # path compression
            return parent[x]

        def union(x, y):
            px, py = find(x), find(y)
            if px == py:
                return 0  # no merge
            if rank[px] > rank[py]:
                parent[py] = px
            elif rank[px] < rank[py]:
                parent[px] = py
            else:
                parent[py] = px
                rank[px] += 1
            return 1  # merged

        res = n  # initially n components
        for u, v in edges:
            res -= union(u, v)

        return res   

```
