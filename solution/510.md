## 1. Problem

510. Inorder Successor in BST II
    
## 2. Summary

Two case:

* If node has **right child** → successor = **leftmost node in right subtree**
* Else → go **up using parent**

  * While node is **right child of parent** → keep moving up
  * First time node is **left child of parent** → parent is successor
* If no such parent → return **None**

## 3. Key Points

* Right child exists → successor = leftmost node in right subtree
* No right child → move up via parent pointers
* Move up while node is right child
* First time node is left child → parent is successor
* If no valid parent → None
* Core: right → down, else → up until first left turn

**Key idea:**
Right subtree → go down
No right → go up until “turn left”

## 4. Code Implementation:

```
class Solution:
    def inorderSuccessor(self, node: 'Node') -> 'Node':
        # Case 1: right subtree exists
        if node.right:
            node = node.right
            while node.left:
                node = node.left
            return node

        # Case 2: no right subtree, go up via parent
        while node.parent and node == node.parent.right:
            node = node.parent

        return node.parent   

```

## 5. Complexity Analysis
    Time：O(n)
        
    Space: O(1)
