## 1. Problem

10. Regular Expression Matching
    
## 2. Summary

dp[i][j] = s[0..i) matches p[0..j)

Init:
dp[0][0] = True
dp[0][j] = (p[j-1] == '*' and dp[0][j-2])

Transition:
if p[j-1] != '*':
    dp[i][j] = dp[i-1][j-1] if match(s[i-1], p[j-1])

else:
    # x* case
    dp[i][j] = dp[i][j-2]          # 0 times (skip x*)
    or
    (match(s[i-1], p[j-2]) and dp[i-1][j])   # 1+ times

match(a,b):
    b == '.' or a == b

## 3. Key Points

`dp[0][j] = whether the empty string "" can match the pattern p[0..j)``

```text
Regex Matching Key Points (. and *)

- dp[i][j] = s[0..i) matches p[0..j)

- '.' matches any single character

- '*' applies ONLY to previous character p[j-2]

- '*' means: previous char appears 0 or more times

- Two cases for '*':
  1) 0 times: dp[i][j] = dp[i][j-2] (remove x*)
  2) 1+ times: if match(s[i-1], p[j-2]) then dp[i][j] |= dp[i-1][j]
     (consume s, keep pattern at j)

- dp[0][j] handles empty string:
  only possible via x* → dp[0][j] = dp[0][j-2]

- Key idea:
  '*' = either skip (0 times) OR consume char (stay in same pattern state)

- dp is OR-combination of all possible matching paths
```

## 4. Code Implementation:


```
class Solution:
    def isMatch(self, s: str, p: str) -> bool:
        m, n = len(s), len(p)
        dp = [[False] * (n + 1) for _ in range(m + 1)]

        dp[0][0] = True

        for j in range(2, n + 1):
            if p[j - 1] == '*':
                dp[0][j] = dp[0][j - 2]

        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if p[j - 1] == '.' or p[j - 1] == s[i - 1]:
                    dp[i][j] = dp[i - 1][j - 1]

                elif p[j - 1] == '*':
                    # case A: 0 time
                    dp[i][j] = dp[i][j - 2]

                    # case B: ≥1 times
                    if p[j - 2] == '.' or p[j - 2] == s[i - 1]:
                        dp[i][j] |= dp[i - 1][j]

        return dp[m][n]         


```
