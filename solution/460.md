## 1. Problem

460. LFU Cache
    
## 2. Summary

LFU is basically: **“group by freq + maintain order within each group”**.

`min_freq` lets you **quickly find the LFU element**.

LFU Cache — Mental Template

Data Structures

* key_table: key → (value, freq)
* freq_table: freq → OrderedDict(keys)  (maintain LRU inside same freq)
* min_freq: smallest frequency in cache

_update_freq(key)

1. get (value, freq) from key_table
2. remove key from freq_table[freq]
3. if this freq list becomes empty:

   * delete it
   * if freq == min_freq → min_freq += 1
4. freq += 1
5. add key to freq_table[freq] (at end)
6. update key_table[key] = (value, freq)

get(key)

* if key not exist → return -1
* update frequency
* return value

put(key, value)

1. if capacity == 0 → return

2. if key exists

   * update value
   * update frequency

3. if key not exists

   * if size == capacity

     * evict from freq_table[min_freq]
     * pop oldest key (LRU within that freq)
   * insert new key with freq = 1
   * min_freq = 1

Eviction Rule

1. remove lowest frequency
2. if tie → remove LRU inside that freq


## 3. Key Points

## **1️⃣ Core Goal**

* Support `get` and `put` in **O(1)**
* Eviction policy:

  1. Remove the **least frequently used** key (lowest `freq`)
  2. If multiple keys have the same frequency, remove the **least recently used** one

---

## **2️⃣ Data Structure Combination**

1. `key -> (value, freq)` : quickly look up a key’s value and frequency
2. `freq -> keys` (Doubly Linked List / OrderedDict) : keeps keys with the same frequency in **usage order**, for fast removal of the oldest key
3. `min_freq` : tracks the current **minimum frequency**

> 🔑 Core idea:
>
> * `freq -> keys` ensures you know **which key is oldest among same freq**
> * `key -> freq` lets you **quickly update a key’s frequency**

---

## **3️⃣ Operation Flow**

### **get(key)**

* If key does not exist → return -1
* Else:

  1. Retrieve `(value, freq)`
  2. Remove key from `freq -> keys[freq]`
  3. Increment `freq` → add key to `freq -> keys[freq+1]`
  4. If old freq list is empty **and** `min_freq == old freq` → `min_freq += 1`
  5. Return `value`

### **put(key, value)**

* If capacity == 0 → return immediately
* If key exists:

  * Update value
  * Call `get(key)` to update frequency
* If key does not exist:

  * If full → remove **oldest key in `freq -> keys[min_freq]`**
  * Insert new key with `freq = 1`
  * Set `min_freq = 1`

---

## **Mental Template**

```text
key -> (val,freq)
freq -> ordered keys
min_freq

get:
  if key not exist: return -1
  val,freq = map[key]
  remove key from freq[freq]
  freq += 1
  add key to freq[freq]
  if freq[freq-1] empty and min_freq==freq-1: min_freq+=1
  return val

put:
  if capacity 0: return
  if key exists: update val, get(key) to update freq
  else:
    if full: remove oldest in freq[min_freq]
    add key with freq=1
    min_freq=1
```


## 4. Code Implementation:

```
from collections import defaultdict, OrderedDict

class LFUCache:

    def __init__(self, capacity: int):
        self.capacity = capacity
        self.size = 0
        self.min_freq = 0
        self.key_table = {}
        self.freq_table = defaultdict(OrderedDict)

    def _update_freq(self, key):
        value, freq = self.key_table[key]

        del self.freq_table[freq][key]
        if not self.freq_table[freq]:
            del self.freq_table[freq]
            if freq == self.min_freq:
                self.min_freq += 1

        freq += 1
        self.freq_table[freq][key] = None
        self.key_table[key] = (value, freq)
        
    def get(self, key: int) -> int:
        if key not in self.key_table:
            return -1
        self._update_freq(key)
        return self.key_table[key][0]

    def put(self, key: int, value: int) -> None:
        if self.capacity == 0:
            return

        if key in self.key_table:
            self.key_table[key] = (value, self.key_table[key][1])
            self._update_freq(key)

        else:
            if self.size >= self.capacity:
                oldest_key, _ = self.freq_table[self.min_freq].popitem(last=False)
                del self.key_table[ oldest_key]
                self.size -= 1
            self.key_table[key] = (value, 1)
            self.freq_table[1][key] = None
            self.min_freq = 1
            self.size += 1

# param_1 = obj.get(key)
# obj.put(key,value)  


```
