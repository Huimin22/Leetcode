## 3. Key Points

**Why not use `path`, and use `memo` instead:**

* `path` represents the *current construction process* → depends on previous choices

* That makes the state **(start, path)** → too large, cannot memoize efficiently ❌

* `memo` requires subproblems to depend only on **position (`start`)**

* In this problem, the result from a position is **independent of path**

👉 So we redefine:

* `dfs(start)` = all sentences from `start`
* Now state = `start` only → can memoize ✅

**Key idea:**
`path` = process (not reusable)
`memo` = results of subproblems (reusable)



**Why return `[""]`?**

* **The Bottom Level (Base):** If `start == n`, return `[""]`. It is like an **empty box**, telling the second-to-last layer: "I am ready over here, you can start loading the goods."
* **The Second-to-Last Layer:** Receives the empty box, puts its own word (e.g., `"dog"`) inside, turning it into `["dog"]`, and then passes this box up.
* **The Third-to-Last Layer:** Receives the box containing `"dog"`, attaches its own word (e.g., `"sand"`) to the front, turning it into `["sand dog"]`, and continues passing it up.
* **The Top Layer:** Finally, what is delivered to your hands is the complete `["cat sand dog"]`.

  
## 4. Code Implementation:

```
class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> List[str]:
        wordSet = set(wordDict)
        memo = {}

        def dfs(start):
            if start in memo:
                return memo[start]
            if start == len(s):
                return [""]  

            res = []
            for end in range(start + 1, len(s) + 1):
                word = s[start:end]
                if word in wordSet:
                    for sub in dfs(end):
                        sentence = word + (" " + sub if sub else "")
                        res.append(sentence)
            memo[start] = res
            return res

        return dfs(0)   

```
