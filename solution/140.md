## 3. Key Points

DFS(start): return all sentences from s[start:]

try all splits: s[start:end]

if valid word → dfs(end)

combine: word + (" " + sub if sub else "")

start == n → return [""] (valid end)

memo[start] = res

[] = invalid path, [""] = valid end


**Why not use `path`, and use `memo` instead:**

* `path` represents the *current construction process* → depends on previous choices

* That makes the state **(start, path)** → too large, cannot memoize efficiently ❌

* `memo` requires subproblems to depend only on **position (`start`)**

* In this problem, the result from a position is **independent of path**

👉 So we redefine:

* `dfs(start)` = all sentences from `start`
* Now state = `start` only → can memoize ✅

**Key idea:**
`path` = process (not reusable)
`memo` = results of subproblems (reusable)

## 4. Code Implementation:

```
class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> List[str]:
        wordSet = set(wordDict)
        memo = {}

        def dfs(start):
            if start in memo:
                return memo[start]
            if start == len(s):
                return [""]  

            res = []
            for end in range(start + 1, len(s) + 1):
                word = s[start:end]
                if word in wordSet:
                    for sub in dfs(end):
                        sentence = word + (" " + sub if sub else "")
                        res.append(sentence)
            memo[start] = res
            return res

        return dfs(0)   

```
