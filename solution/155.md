## 1. Problem

155. Min Stack
    
## 2. Summary

```text
Use two stacks:
1️⃣ stack → store all values
2️⃣ min_stack → store current minimums

push(val):
    stack.push(val)
    if min_stack empty or val <= min_stack.top():
        min_stack.push(val)

pop():
    if stack.top() == min_stack.top():
        min_stack.pop()
    stack.pop()

top():
    return stack.top()

getMin():
    return min_stack.top()
```


## 3. Key Points

* min_stack only tracks min history
* top() doesn’t modify anything
* pop() may sync min_stack if current min removed
* O(1) for all operations

## 4. Code Implementation:


```
class MinStack:

    def __init__(self):
        self.stack = []
        self.min_stack = []  

    def push(self, val: int) -> None:
        self.stack.append(val)
        if not self.min_stack or val <= self.min_stack[-1]:
            self.min_stack.append(val)
       

    def pop(self) -> None:
        if self.stack[-1] == self.min_stack[-1]:
            self.min_stack.pop()
        self.stack.pop()
    
    def top(self) -> int:
        return self.stack[-1]
        

    def getMin(self) -> int:
        return self.min_stack[-1]
```
