## 1. Problem

401. Binary Watch
     
## 2. Summary

Split lights between hour & minute → generate combinations → filter by range → Cartesian product → format string.


 Mental Template

* LEDs:

  * hours = [8,4,2,1] (0–11)
  * minutes = [32,16,8,4,2,1] (0–59)

* Total lights on = turnedOn

1. For h_count in 0 → min(4, turnedOn):

   * m_count = turnedOn - h_count
   * if m_count > 6 → skip

2. Generate all hour sums using h_count LEDs

   * keep hour < 12

3. Generate all minute sums using m_count LEDs

   * keep minute < 60

4. Combine:

   * for each valid hour
   * for each valid minute
   * format → "h:mm" (minute zfill(2))


## 3. Key Points

* Each LED represents a fixed value.
* Total LEDs on = turnedOn.
* Split lights between hour (max 4) and minute (max 6).
* Generate combinations separately for hours and minutes.
* Hour < 12, Minute < 60.
* Result = valid hours × valid minutes.
* Format: hour no leading zero, minute two digits.

## 4. Code Implementation:

```
 class Solution:
    def readBinaryWatch(self, turnedOn: int) -> List[str]:
        hours_led = [8,4,2,1]
        minutes_led = [32,16,8,4,2,1]
        res = []

        for h_count in range(0, min(4, turnedOn)+1):
            m_count = turnedOn - h_count
            if m_count > 6:
                continue
            
            hours = []
            for combo in combinations(hours_led, h_count):
                hour_sum = sum(combo)
                if hour_sum < 12:
                    hours.append(hour_sum)

            minutes = []
            for combo in combinations(minutes_led, m_count):
                minute_sum = sum(combo)
                if minute_sum < 60:
                    minutes.append(minute_sum)

            for h in hours:
                for m in minutes:
                    time_str = str(h) + ":" + str(m).zfill(2)
                    res.append(time_str)


        return res  
```
