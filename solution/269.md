## 1. Problem

# 269. Alien Dictionary(Locked)

## Description

There is a new alien language that uses the Latin alphabet. However, the order among the letters is unknown to you.

You are given a list of non-empty strings `words`, where the words are sorted lexicographically according to the rules of this new language.

Derive the order of letters in this language.

---

## Example 1

```
Input: words = ["wrt","wrf","er","ett","rftt"]
Output: "wertf"
```

---

## Example 2

```
Input: words = ["z","x"]
Output: "zx"
```

---

## Example 3

```
Input: words = ["z","x","z"]
Output: ""
Explanation: The order is invalid, so return "".
```

---

## Constraints

* 1 <= words.length <= 100
* 1 <= words[i].length <= 100
* words[i] consists of lowercase English letters

---

## Notes

* You may assume all letters are in lowercase English letters.
* If a is a prefix of b, then a must appear before b in the given dictionary.
* If the order is invalid, return an empty string.
* There may be multiple valid answers. Return any of them.

Test with LC 49.

## 2. Summary

1. init graph
2. build graph  check if prefix invalid
3. topo sort (BFS)
4. check cycle

```text
1️⃣ Prefix invalid case
["abc", "ab"] → ❌
If the first word is longer and starts with the second word, it's invalid.

2️⃣ Include all characters in the graph

Even if there are no edges:
["a", "b", "c"]

👉 You still need to return "abc" (or any valid order)
```

## 3. Key Points

Use set to store neighbors (no duplicate edges),
and check before adding to avoid double counting indegree.

## 4. Code Implementation:

```
class Solution:
    def alienOrder(self, words):
        graph = {c: set() for word in words for c in word}
        indegree = {c: 0 for c in graph}

        for i in range(len(words) - 1):
            w1, w2 = words[i], words[i+1]

            if len(w1) > len(w2) and w1.startswith(w2):
                return ""

            for j in range(min(len(w1), len(w2))):
                if w1[j] != w2[j]:
                    if w2[j] not in graph[w1[j]]:
                        graph[w1[j]].add(w2[j])
                        indegree[w2[j]] += 1
                    break

        q = deque([c for c in indegree if indegree[c] == 0])
        res = []

        while q:
            c = q.popleft()
            res.append(c)
            for nei in graph[c]:
                indegree[nei] -= 1
                if indegree[nei] == 0:
                    q.append(nei)

        if len(res) == len(graph):
            # print("".join(res))

            return "".join(res) 
        else:
            return ""   
```
