## 1. Problem

138. Copy List with Random Pointer
    
## 2. Summary

1. **Map nodes**: old → new (copy values).
2. **Set pointers**: new.next = map[old.next], new.random = map[old.random].
3. **Return**: map[head].

## 3. Key Points

* Use hash map: old node → new node.
* First pass: copy nodes (values only).
* Second pass: set `.next` and `.random` via map.
* `.get()` handles `None`.
* Return mapped head.

## 4. Code Implementation:


```
class Solution:
    def copyRandomList(self, head: 'Optional[Node]') -> 'Optional[Node]':
        if not head:
            return None

        n_dict = {}
        cur = head
        while cur:
            n_dict[cur] = Node(cur.val)
            cur = cur.next
        
        cur = head
        while cur:
            n_dict[cur].next = n_dict.get(cur.next)
            n_dict[cur].random = n_dict.get(cur.random)
            cur = cur.next

        return n_dict[head]   

```

## 5. Complexity Analysis
    Time：O(n)
        
    Space: O(1)
