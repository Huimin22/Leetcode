## 1. Problem

270. Closest Binary Search Tree Value

Given a non-empty binary search tree and a target value, find the value in the BST that is closest to the target.

Note:

Given target value is a floating point.
You are guaranteed to have only one unique value in the BST that is closest to the target.
Example:

Input: root = [4,2,5,1,3], target = 3.714286

```
     4
    
   /  \
   
  2    5
  
 / \
 
1   3

```

Output: 4
 
## 2. Summary

BST closest value:

Start at root, track best = root.val
While node:
compare |node.val - target| vs |best - target| → update best
if target < node.val → go left
else → go right
return best

## 3. Key Points

* Use BST property to guide search (no full traversal)
* Track current best value during traversal
* Update best when closer to target
* If target < node.val → go left
* Else → go right
* O(h) time, O(1) space (iterative)

## 4. Code Implementation:


```
class Solution:
    def closestValue(self, root, target):
        res = root.val
        cur = root
        while cur:
            if abs(cur.val - target) < abs(res - target):
                res = cur.val
            if target < cur.val:
                cur = cur.left
            else:
                cur = cur.right
        return res   
```

## 5. Complexity Analysis
    Time：O(n)
        
    Space: O(1)
