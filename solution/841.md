## 1. Problem

841. Keys and Rooms
    
## 2. Summary

BFS

* Graph: room = node, keys = neighbors

* Start from 0

* queue = [0], visited = {0}

* While queue:

  * pop room
  * for key in rooms[room]:

    * if not visited:

      * add to visited
      * push to queue

* Return len(visited) == n

## 3. Key Points

* Start from room 0 (only unlocked)
* rooms already = adjacency list (no build graph)
* keys = neighbors
* use visited to avoid revisit
* BFS/DFS both work
* no level / distance needed
* check len(visited) == n

## 4. Code Implementation:


```
class Solution:
    def canVisitAllRooms(self, rooms: List[List[int]]) -> bool:
        n = len(rooms)
        v = set([0])
        q = deque([0])

        while q:
            cur_n = q.popleft()
            for key in rooms[cur_n]:
                if key not in v:
                    q.append(key)
                    v.add(key)
        return n == len(v)
   


```

## 5. Complexity Analysis
    Time：O(n)
        
    Space: O(1)
