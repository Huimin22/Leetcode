## 2. Summary

```
flatten board → string state
neighbors = {0:[1,3],1:[0,2,4],2:[1,5],3:[0,4],4:[1,3,5],5:[2,4]}
queue = deque([(state, 0)]), visited = {state}
while queue:
    state, steps = queue.popleft()
    if state == target: return steps
    idx = state.index('0')
    for nei in neighbors[idx]:
        swap 0 and state[nei] → new_state
        if new_state not in visited:
            visited.add(new_state)
            queue.append((new_state, steps+1))
return -1
```

* BFS over states
* Generate neighbors dynamically using 0 index
* Use visited to avoid duplicate states
* First time reach target → shortest moves

## 3. Key Points

* Flatten board → string state
* Precompute neighbors by index
* BFS queue with (state, steps)
* Find 0 index, swap with neighbors → new states
* Use visited to avoid duplicates
* First reach target → return steps
* Return -1 if unreachable

list[str] → "".join(list)

list[int] → "".join(str(x) for x in list)

## 4. Code Implementation:

```
from collections import deque
from typing import List

class Solution:
    def slidingPuzzle(self, board: List[List[int]]) -> int:
        rows, cols = 2, 3
        target = "123450"
        start = "".join(str(num) for row in board for num in row)
        neighbors = {}
        for r in range(rows):
            for c in range(cols):
                idx = r * cols + c
                nei = []
                for dr, dc in [(-1,0),(1,0),(0,-1),(0,1)]:
                    nr, nc = r + dr, c + dc
                    if 0 <= nr < rows and 0 <= nc < cols:
                        nei_idx = nr * cols + nc
                        nei.append(nei_idx)
                neighbors[idx] = nei
        queue = deque([(start, 0)])
        visited = set([start])
        while queue:
            state, steps = queue.popleft()
            if state == target:
                return steps
            idx = state.index('0')
            for nei in neighbors[idx]:
                lst = list(state)
                lst[idx], lst[nei] = lst[nei], lst[idx]
                new_state = "".join(lst)
                if new_state not in visited:
                    visited.add(new_state)
                    queue.append((new_state, steps + 1))
        return -1   

```
