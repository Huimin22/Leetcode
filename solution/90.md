## 2. Summary

Subsets II (with duplicates) — Mental Template

Sort first.

State = (path, start_index)

Every node → add path to result.

Loop from current index forward only:

for i in range(start, n):
if i > start and nums[i] == nums[i-1]:
skip   # same-level dedup
choose nums[i]
dfs(i+1)
undo

## 3. Key Points

* Use start index to prevent reuse
* Dedup only on same level
* No used[] needed

## 4. Code Implementation:


```
class Solution:
    def subsetsWithDup(self, nums: List[int]) -> List[List[int]]:
        nums.sort()
        res = []
        def dfs(path, idx):
            res.append(path[:])
            for i in range(idx, len(nums)):
                if i > idx and nums[i] == nums[i-1]:
                    continue
                path.append(nums[i])
                dfs(path, i+1)
                path.pop()
        dfs([], 0)
        return res   

```

## 8. Note

1. Ignored `start index` — looped from 0 instead of `range(idx, n)`.
2. Advanced recursion incorrectly — used `idx+1` instead of `i+1`.
3. No same-level dedup — missing `if i > idx and nums[i] == nums[i-1]: continue`.
4. Broke subset structure — allowed reusing previous elements.
5. Returned wrong value — returned `dfs` instead of `res`.

**Second**

```text
idx = start index for choosing numbers in the current recursion level
i = index of the number currently chosen

for i in range(idx, n) → decide which number to choose at this level

after choosing nums[i]:
next level must start from i+1
to avoid reusing the same element

dfs(path, i+1) → decide the start index for the next recursion level
```

**Third**

 dfs(i+1, path)  

 * In the DFS loop, the recursive call must use `i+1`, meaning the current element is chosen and the next level can only start from the next element.
* The DFS start index for the next level depends only on the current index `i`, not on the length of `path`.
* Forgetting `i+1` can cause duplicate subsets or infinite recursion.


* `idx` (or `start`) **only tells DFS where to start the current loop**.
* It does **not control which element the next level can choose**—that is determined by the current loop variable `i`.
* In other words:

  1. First call: `dfs(0, [])` → start from index 0.
  2. Inside the loop: pick `i`, then **next DFS starts at `i+1`**.
  3. `idx` is just the **starting point for the current loop**, each recursive level calculates its own next start from the chosen `i`.

Mathematically, it’s like **combinations**: once you pick element `i`, the next pick can only come from elements after `i`.
