## 1. Problem

139. Word Break
     
## 2. Summary

**DP**

dp[i] = True if ∃ j in [0, i) such that dp[j] and s[j:i] in wordSet

## 3. Key Points

* `dp[i]` = True if `s[0:i]` can be segmented.
* `dp[0] = True` (empty string).
* `dp[i] = True` if ∃ j < i: `dp[j]` and `s[j:i] in wordSet`.
* Convert `wordDict` to set for fast lookup.
* Iterate i = 1..n, j = 0..i-1.
* Return `dp[n]`.

## 4. Code Implementation:

```
class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        n_wordDict = set(wordDict)
        n = len(s)
        dp = [False]*(n+1)
        dp[0] = True
        for i in range(1, n+1):
            for j in range(i):
                if dp[j] and s[j:i] in n_wordDict:
                    dp[i] = True
                    break
    
        return dp[n]   
```

## 5. Complexity Analysis
    Time：O(n)
        
    Space: O(1)
