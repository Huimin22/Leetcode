## 2. Summary

```
173. BST Iterator — Mental Template

Goal:
Return next smallest in BST (inorder traversal).

Core Idea:
Use stack to simulate inorder.
Stack top = next smallest.

Init:
pushLeft(root)

pushLeft(node):
    while node:
        stack.append(node)
        node = node.left

next():
    node = stack.pop()
    if node.right:
        pushLeft(node.right)
    return node.val

hasNext():
    return stack not empty

Key Insight:
Left first.
Right delayed.
Stack always stores path to next smallest.
```

## 3. Key Points

- Inorder traversal of BST = ascending order
- Use stack to simulate recursion
- Stack stores path to next smallest node
- Initialization: push all left nodes from root
- next():
    pop top (current smallest)
    if has right child → pushLeft(right)
- hasNext():
    stack not empty


If the stack only stores **values**:

* Once you pop a value, you no longer know where its right subtree is.
* Therefore, you can’t do `pushLeft(node.right)`.
* In-order traversal cannot continue correctly.

So you must store **node objects** in the stack, because then you can:

* Access `.val` → to return the result.
* Access `.left` / `.right` → to continue the traversal.

## 4. Code Implementation:

```
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class BSTIterator:

    def __init__(self, root: Optional[TreeNode]):
        self.stack = []
        self._pushLeft(root)
    
    def _pushLeft(self, node):
        while node:
            self.stack.append(node)
            node = node.left
        
    def next(self) -> int:
        node = self.stack.pop()
        if node.right:
            self._pushLeft(node.right)
        return node.val

    def hasNext(self) -> bool:
        return len(self.stack)>0

```
