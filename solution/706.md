## 2. Summary

```text id="t0v0p5"
HashMap = array of buckets
index = key % size

put:
    if key exists in bucket → update pair[1]
    else append [key,value]

get:
    search bucket → return value or -1

remove:
    search bucket → remove pair
```

## 3. Key Points

```text id="y1k3n8"
- Use array of buckets, size = 1000.  
- Index = key % size.  
- Bucket stores [key, value] pairs.  
- put: update if key exists, else append.  
- get: search bucket, return value or -1.  
- remove: search bucket, delete pair.
```

## 4. Code Implementation:

```
class MyHashMap:

    def __init__(self):
        self.size = 769
        self.table = [[] for _ in range(self.size)]

    def put(self, key: int, value: int) -> None:
        index = key % self.size
        bucket = self.table[index]

        for pair in bucket:
            if pair[0] == key:
                pair[1] = value
                return

        bucket.append([key, value])

    def get(self, key: int) -> int:
        index = key % self.size
        bucket = self.table[index]

        for k, v in bucket:
            if k == key:
                return v

        return -1

    def remove(self, key: int) -> None:
        index = key % self.size
        bucket = self.table[index]

        for i, (k, v) in enumerate(bucket):
            if k == key:
                bucket.pop(i)
                return
```

**Third**
* `__init__`: used undefined `size` instead of `self.size`.
* `put`: always appended new `(key, value)` even if key existed → duplicates.
* `put`: used tuple `(key, value)` → immutable, cannot update `pair[1]`.
* `remove`: iterated with pop but continued loop or returned `-1` → unnecessary/buggy.
* `remove`: shadowed loop variable `i` with bucket index.
