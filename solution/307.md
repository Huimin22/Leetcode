## 1. Problem

307. Range Sum Query - Mutable
    
## 2. Summary

### Mental Template

```text
1. tree[i] stores partial sums of nums (1-based index)
2. lowbit(i) = i & -i, length of tree[i]’s interval
3. _add(i, delta): add delta to all intervals containing nums[i-1]
   while i <= n:
       tree[i] += delta
       i += lowbit(i)
4. _prefix_sum(i): sum nums[0..i-1] using tree
   res = 0
   while i > 0:
       res += tree[i]
       i -= lowbit(i)
5. update(index, val):
   delta = val - nums[index]
   nums[index] = val
   _add(index + 1, delta)
6. sumRange(left, right):
   return _prefix_sum(right + 1) - _prefix_sum(left)
7. Initialize tree: for i, val in enumerate(nums):
   _add(i + 1, val)
```

## 3. Key Points

* **tree[i] = partial sum of nums**, not the element itself
* **_add** propagates the delta to all relevant intervals
* **_prefix_sum** accumulates partial sums to get prefix sum
* **1-based tree** simplifies lowbit logic

## 4. Code Implementation:
```
class NumArray:
    def __init__(self, nums):
        self.n = len(nums)
        self.nums = nums[:]              # Store a copy of the original array
        self.tree = [0] * (self.n + 1)   # Binary Indexed Tree (1-based)
        for i, val in enumerate(nums):
            self._add(i + 1, val)        # Initialize the tree

    # Internal method: update the BIT
    def _add(self, i, delta):
        while i <= self.n:
            self.tree[i] += delta
            i += i & -i  # Move to next responsible node (lowbit)

    # Internal method: compute prefix sum
    def _prefix_sum(self, i):
        res = 0
        while i > 0:
            res += self.tree[i]
            i -= i & -i  # Move to parent node
        return res

    # Update element nums[index] = val
    def update(self, index, val):
        delta = val - self.nums[index]
        self.nums[index] = val
        self._add(index + 1, delta)

    # Query the sum of range [left, right], inclusive
    def sumRange(self, left, right):
        return self._prefix_sum(right + 1) - self._prefix_sum(left)    


# Example of usage:
# obj = NumArray(nums)
# obj.update(index, val)
# param_2 = obj.sumRange(left, right)   

```
