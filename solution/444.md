## 1. Problem

#### 444. Sequence Reconstruction (locked)

```markdown
Check whether the original sequence `org` can be uniquely reconstructed 
from the sequences in `seqs`.  

The `org` sequence is a permutation of the integers from 1 to n, 
with 1 ≤ n ≤ 10^4.  

Reconstruction means building a shortest common supersequence of the sequences 
in `seqs` (i.e., a shortest sequence so that all sequences in `seqs` are 
subsequences of it).  

Determine whether there is only **one sequence** that can be reconstructed 
from `seqs` and it is the `org` sequence.

Example 1:

**Input:**
org: [1,2,3], seqs: [[1,2],[1,3]]

**Output:**
false

**Explanation:**
[1,2,3] is not the only one sequence that can be reconstructed, because [1,3,2] is also a valid sequence that can be reconstructed.

Example 2:

**Input:**
org: [1,2,3], seqs: [[1,2]]

**Output:**
false

**Explanation:**
The reconstructed sequence can only be [1,2].

Example 3:

**Input:**
org: [1,2,3], seqs: [[1,2],[1,3],[2,3]]

**Output:**
true

**Explanation:**
The sequences [1,2], [1,3], and [2,3] can uniquely reconstruct the original sequence [1,2,3].

Example 4:

**Input:**
org: [4,1,5,2,6,3], seqs: [[5,2,6,3],[4,1,5,2]]

**Output:**
true
```

    
## 2. Summary

1. Standard topo sort structure.
2. **Uniqueness is checked** by seeing if `len(queue) > 1` at any step.
3. Compare reconstructed sequence with `org`.
4. org defines nodes, seqs defines edges. When we need to check nodes. use the source from org.

## 3. Key Points

"The definition of 'indegree' is the number of edges pointing to the current node. In other words, indegree represents the number of times a node is depended on, or the number of its 'prerequisites'."

* Use `defaultdict(set)` for graph.
* Initialize indegree with `{x:0 for x in org}`.
* Check numbers in seqs with `num not in indegree`.
* Loop edges with `for i in range(len(seq)-1)`.
* Use deque for nodes with indegree 0.
* Return False if `len(q) > 1`.
* Final result: `res == org`.

**Indegree table = count of prerequisites**
The indegree of each number represents how many numbers that **must come before it** have not yet been processed.

**Topological sort uses the indegree table to control order:**

* Only numbers with indegree 0 can be taken → ensures all their prerequisite numbers have already been placed.
* Each time a number is taken, decrement the indegree of its neighbors → neighbors may become candidates for the next step.

  
## 4. Code Implementation:

```
from collections import defaultdict, deque

def sequenceReconstruction(org, seqs):
    if not seqs:
        return False

    # Initialize graph and indegree
    graph = defaultdict(set)
    indegree = {x: 0 for x in org}

    # Build graph and indegree table
    for seq in seqs:
        # check if the num is valid in org
        for num in seq:
            if num not in indegree:
                return False

        for i in range(len(seq) - 1):
            prev, nex = seq[i], seq[i+1]
            if nex not in graph[prev]:
                graph[prev].add(nex)
                indegree[nex] += 1

    # Topological sort
    queue = deque([x for x in org if indegree[x] == 0])
    res = []

    while queue:
        if len(queue) > 1:  # multiple choices → not unique
            return False
        node = queue.popleft()
        res.append(node)
        for nei in graph[node]:
            indegree[nei] -= 1
            if indegree[nei] == 0:
                queue.append(nei)

    return res == org   
```
