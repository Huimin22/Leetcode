## 1. Problem
76. Minimum Window Substring （hard）
    
## 2. Summary

“Expand right to satisfy → shrink left to minimize → track formed”

## 1️⃣ Core Idea of Sliding Window

The window `[left, right]` represents the current substring under consideration.

* **`right` → expand the window**

  * Each time `right += 1`, add the new character to the window.
  * Update `window_counts`. If a character in the window reaches the required count in `dict_t`, increment `formed += 1`.
  * Goal: **find a window that satisfies the condition** (`formed == required`).

* **`left` → shrink the window**

  * When the window already satisfies the condition (`formed == required`), try **shrinking from the left**.
  * Each time `left += 1`, remove the leftmost character from the window.
  * Update `window_counts`. If removing it makes its count less than required, decrement `formed -= 1`.
  * Now the window **no longer satisfies the condition**, so stop shrinking and move `right` again.

---

## 2️⃣ Role of `formed`

* `formed` tracks **how many target characters in the current window have met their required counts**.
* When `formed == required`, it means **all target characters in the window meet the requirement**.
* While shrinking the window, if `formed` decreases, the condition is broken → stop shrinking.

---

## 3️⃣ Intuitive Analogy for Left and Right Pointers

| Pointer | Purpose                              | Analogy                                                         |
| ------- | ------------------------------------ | --------------------------------------------------------------- |
| right   | expand the window, add characters    | Pull the net to the right to catch more fish                    |
| left    | shrink the window, remove characters | Tighten the left side of the net to leave only the minimum fish |

---

## 4️⃣ While Loop Logic

```python
while left <= right and formed == required:
    # 1. Record the smallest window
    if right - left + 1 < ans[0]:
        ans = (right - left + 1, left, right)
    
    # 2. Remove the leftmost character
    c_left = s[left]
    window_counts[c_left] -= 1
    if c_left in dict_t and window_counts[c_left] < dict_t[c_left]:
        formed -= 1  # condition broken

    # 3. Move left boundary to the right
    left += 1
```

* This loop **shrinks the window as much as possible while still satisfying the condition**.
* Once the condition is broken, break the loop and continue expanding with `right` to find the next possible window.

---

## ✅ Summary

* **`right`** → expand the window, find potential valid substrings
* **`left`** → shrink the window, find the minimum valid window
* **`c_left`** → temporarily store the leftmost character, update counts, and check if the window still satisfies the condition
* **`formed`** → indicates whether the current window satisfies the requirement
* **Loop goal** → find the **smallest window that still satisfies all requirements**


## 3. Key Points

1. **Sliding Window + Hash Maps**

   * `dict_t` → counts of chars in `t`
   * `window_counts` → counts of chars in current window

2. **Formed Counter**

   * `formed` = number of unique `t` chars currently satisfied in window
   * Window is valid if `formed == required`

3. **Expand Right Pointer**

   * Include new char in `window_counts`
   * If char satisfies requirement → `formed += 1`

4. **Shrink Left Pointer** (while window valid)

   * Try to minimize window length
   * Remove left char from `window_counts`
   * If removal breaks requirement → `formed -= 1`

5. **Update Answer**

   * Keep track of smallest valid window (`min_len, start, end`)

6. **Return Result**

   * Slice `s[start:end+1]` if found, else ""

## 4. Code Implementation:


```
class Solution:
    def minWindow(self, s: str, t: str) -> str:
        if not s:
            return ""

        target_dict = Counter(t)
        target_cnt = len(target_dict)
        cur_dict = defaultdict(int)
        formed_cnt = 0
        res = [float('inf'), 0 , 0]
        left, right = 0, 0

        while right < len(s):
            c_right = s[right] 
            cur_dict[c_right] += 1

            if c_right in target_dict and cur_dict[c_right] == target_dict[c_right]:
                formed_cnt += 1

            while left <= right and formed_cnt == target_cnt:
                if right-left+1 < res[0]:
                    res = [right-left+1, left, right]

                c_left = s[left] 
                cur_dict[c_left] -= 1

                if c_left in target_dict and cur_dict[c_left] < target_dict[c_left]:
                    formed_cnt -= 1
                
                left += 1

            right += 1
        
        if res[0] == float("inf"):
            return ""
        
        else:
            return s[res[1]: res[2]+1]

```
