## 1. Problem

115. Distinct Subsequences
    
## 2. Summary

dp[i][j] = ways s[:i] → t[:j]

dp[0] = 1

for i in s:
for j in reverse:

dp[j] = dp[j] + dp[j-1]

### **If `s[i-1] == t[j-1]` (Current characters match):**

**Option 1: Use `s[i-1]` to match `t[j-1]`**
Since `s[i-1]` is now responsible for matching `t[j-1]`, the remaining task is to find how many ways the first `i-1` characters of `s` can match the first `j-1` characters of `t`.
*   **Number of ways:** `dp[i-1][j-1]`

**Option 2: "Ignore" `s[i-1]` even though it matches `t[j-1]`**
Even though `s[i-1]` and `t[j-1]` are the same, we "stubbornly" choose not to use this specific character for the match. Instead, we want to see how many ways the **previous** part of `s` (the first `i-1` characters) has already successfully formed the full target `t[:j]`.
*   *Example:* If `s = "rabb"` and `t = "rab"`, when we look at the second `'b'`, we can choose to ignore it and use the first `'b'` which already completed the "rab" match.
*   **Number of ways:** `dp[i-1][j]`

**Final Transition Equation:**
`dp[i][j] = (Ways using the match) + (Ways ignoring the match) = dp[i-1][j-1] + dp[i-1][j]`

## 3. Key Points

use / skip s[i]
reverse j to keep dp[j-1] from prev row

## 4. Code Implementation:

```
class Solution:
    def numDistinct(self, s: str, t: str) -> int:
        m, n = len(s), len(t)
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        
        for i in range(m + 1):
            dp[i][0] = 1
            
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if s[i - 1] == t[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + dp[i - 1][j]
                else:
                    dp[i][j] = dp[i - 1][j]
                    
        return dp[m][n] 
        
```


```
class Solution:
    def numDistinct(self, s: str, t: str) -> int:
        m, n = len(s), len(t)
        dp = [0] * (n + 1)
        dp[0] = 1
        for i in range(1, m + 1):
            for j in range(n, 0, -1):
                if s[i - 1] == t[j - 1]:
                    dp[j] += dp[j - 1]
        return dp[n]   


```
