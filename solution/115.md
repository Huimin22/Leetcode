## 1. Problem

115. Distinct Subsequences
    
## 2. Summary

dp[i][j] = ways s[:i] → t[:j]

init:
dp[0] = 1

transition:
for i in s:
for j in reverse:
if s[i-1] == t[j-1]:
dp[j] = dp[j] + dp[j-1]
else:
dp[j] = dp[j]

## 3. Key Points

use / skip s[i]
reverse j to keep dp[j-1] from prev row

## 4. Code Implementation:


```
class Solution:
    def numDistinct(self, s: str, t: str) -> int:
        m, n = len(s), len(t)
        dp = [0] * (n + 1)
        dp[0] = 1
        for i in range(1, m + 1):
            for j in range(n, 0, -1):
                if s[i - 1] == t[j - 1]:
                    dp[j] += dp[j - 1]
        return dp[n]   


```

## 5. Complexity Analysis
    Time：O(n)
        
    Space: O(1)
