## 2. Summary

dp[i][j] = # ways s[0:i] matches t[0:j]

init:
dp[0][0] = 1
dp[i][0] = 1 (delete all from s)

transition:
if s[i-1] == t[j-1]:
    dp[i][j] = dp[i-1][j-1] + dp[i-1][j]
else:
    dp[i][j] = dp[i-1][j]

answer: dp[m][n]

## 3. Key Points

- confused dp meaning: “ways” vs “match state”
- missed that s[i-1] can be skipped (delete case always exists)
- incorrectly thought match is only diagonal transition
- forgot dp[i][0] = 1 (empty t always match via deletions)
- unclear separation of “use char” vs “skip char”
- boundary indexing off-by-one (i-1, j-1 confusion)
